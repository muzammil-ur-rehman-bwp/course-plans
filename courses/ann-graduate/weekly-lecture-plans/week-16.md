# Week 16 Lecture Plan — Artificial Neural Network (Graduate)
## Topic: Capstone Research Presentations; Course Review

**Duration:** 2 hours lecture + 3 hour seminar (both periods used for presentations)

### Learning Objectives (Bloom's Level)
1. Present an original research-style capstone project in a conference-style talk format.
   (*Create, Evaluate*)
2. Evaluate peers' capstone presentations constructively against the capstone rubric criteria.
   (*Evaluate*)
3. Synthesize the course's six theoretical pillars into a single coherent map. (*Understand, Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–2:00 | Capstone presentations (lecture period) | Student/pair presentations, time-boxed per `assignments/capstone-rubric.md`, with Q&A |
| 2:00–4:00 | Capstone presentations (seminar period, continued) | Remaining presentations + Q&A |
| 4:00–4:30 | Course review | Recap of the course map: approximation theory → automatic differentiation → initialization/normalization theory → optimization-landscape theory → generalization theory → modern research directions |
| 4:30–5:00 | Where this leads next | Pointers to the sibling Deep Learning and Machine Learning graduate courses, and to current theoretical ML venues (NeurIPS, ICML) for continued reading |

### Materials/Equipment
- Presentation schedule and room A/V setup
- Capstone rubric (for instructor and peer scoring)

### Formative Check (in-class)
Each student submits one written peer-feedback note (strength + one question) for at least two
other presentations.

### Link to Lab/Assessment
No lab this week. **Capstone final paper + presentation due** (see
`assignments/capstone-rubric.md`).
