# Lab Manual 15 — Capstone Experiment Execution and Draft Paper

**Duration:** 3 hours | **Prerequisite:** Week 15 lecture; an approved capstone proposal**

## Objectives
Run the capstone's planned reproduced/extended experiment, collect results across multiple
random seeds where applicable, and produce a written-paper draft.

## Setup
Whatever software/environment the individual capstone project requires (per the approved
proposal).

## Procedure
1. **Task A — Experiment execution:** run the planned experiment (or its reproduced/extended
   variant); for any stochastic method, run at least 3 random seeds and report the spread, not
   just one run's numbers.
2. **Task B — Results analysis:** summarize results in a table/plot; explicitly state whether
   they support, partially support, or do not support the motivating question — a correctly
   analyzed negative/partial result is an acceptable, gradeable outcome.
3. **Task C — Written draft:** produce a short written-paper draft (introduction, related work,
   method, results, limitations) following the conference-short-paper structure from
   `assignments/capstone-rubric.md`.
4. **Task D — Practice-talk prep:** prepare a 5–7 minute practice-talk outline from the draft
   paper, for this week's peer-feedback session.

## Expected Output
A results table/plot (Task A–B), a written-paper draft (Task C), and a practice-talk outline
(Task D).

## Submission
Submit the written-paper draft and practice-talk outline by the end of the lab session; this is
the capstone's Week 15 deliverable (see `course-plan.md` §6).
