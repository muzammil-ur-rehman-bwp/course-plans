# Week 16 Lecture Plan — Deep Learning (Graduate)
## Topic: Capstone Research Presentations; Course Review

**Duration:** 2 hours presentations + 3 hour presentations/review session

### Learning Objectives (Bloom's Level)
1. Present an original research-style capstone project in conference-talk format. (*Create*)
2. Field audience questions accurately and honestly, including about limitations. (*Evaluate*)
3. Synthesize the course's architecture-and-technique map as a coherent whole. (*Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:30 | Capstone presentations, part 1 | Student/pair presentations (conference-talk format: problem, related work, method, results, limitations, Q&A) |
| 1:30–1:40 | Break | — |
| 1:40–3:10 | Capstone presentations, part 2 | Remaining presentations |
| 3:10–3:30 | Final review | Course map recap; integration points with sibling graduate courses |

### Materials/Equipment
- Presentation A/V setup, timer
- Capstone grading rubric (`assignments/capstone-rubric.md`) for instructor scoring during talks

### Formative Check (in-class)
Audience members (students) each submit one written question for a presentation other than their
own, used to seed Q&A.

### Link to Lab/Assessment
No lab this week. Deliverable: capstone final paper submission + presentation
(`assignments/capstone-rubric.md`).
