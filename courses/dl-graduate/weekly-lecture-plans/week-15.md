# Week 15 Lecture Plan — Deep Learning (Graduate)
## Topic: Research Project Work Session

**Duration:** 2 hours seminar + 3 hour lab/work session

### Learning Objectives (Bloom's Level)
1. Execute the capstone's reproduced or extended experiment and draft the written paper.
   (*Create*)
2. Give and receive structured, specific peer feedback on a practice research talk. (*Evaluate*)
3. Deliver the Paper Critique & Presentation assignment. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:50 | Paper Critique & Presentation session | Student presentations (5 min + 2 min Q&A each) |
| 0:50–1:00 | Break | — |
| 1:00–1:40 | Capstone practice talks | 2–3 students/pairs give a short practice run of their capstone talk |
| 1:40–2:00 | Structured peer feedback | Peers complete a feedback worksheet (problem clarity, experiment soundness, honesty about limitations) |

### Materials/Equipment
- Peer-feedback worksheet
- Presentation timer

### Formative Check (in-class)
Each peer-feedback worksheet must name one specific strength and one specific, actionable
improvement for the practice talk it reviews.

### Link to Lab/Assessment
Lab 15: Capstone work session — run the planned experiment, collect results, and produce a
written-paper draft (see `lab-manuals/lab-15.md`).
