# Lab Assignment 1 — Environment Setup & Landscape Mapping (Graded)

**Weight:** part of the weekly Lab Work component (10% of course grade, averaged across all labs).

## Deliverable
Submit `lab01.ipynb` (or accompanying document) containing Tasks A–D from `lab-manuals/lab-01.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A complete (environment check runs and reports versions/GPU status) | 2 |
| Task B complete (checklist filled out honestly, with gaps noted) | 3 |
| Task C complete (landscape map skimmed; evidenced by Task D's content) | 1 |
| Task D complete (150–250 word research-interest paragraph, genuinely reflective) | 4 |
| **Total** | **10** |

## Notes
- Task B is graded on completion and honesty, not on how many items are checked off — a student
  who accurately flags several gaps for review scores as well as one who flags none, provided the
  self-assessment is genuine.
- There is no "wrong" answer for Task D; it is graded on effort and specificity, not on which
  topic is chosen.
