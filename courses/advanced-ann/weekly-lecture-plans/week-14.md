# Week 14 Lecture Plan — Advanced Artificial Neural Network (Post Graduate)
## Topic: Current Open Problems Survey

**Duration:** 2 hours lecture + 3 hour seminar (critical-writing/discussion format)

### Learning Objectives (Bloom's Level)
1. State 2–3 currently active, unsolved questions in neural-network theory precisely. (*Understand*)
2. Evaluate what the strongest current partial answer to each actually establishes versus what it
   is sometimes informally taken to establish. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Framing | This survey is explicitly flagged as fast-moving; specifics may date quickly |
| 0:10–0:40 | Open question 1 | A unified theory of feature learning's benefits beyond NTK/mean-field limits |
| 0:40–1:10 | Open question 2 | Simultaneously tight, reparameterization-invariant, practically computable generalization bounds |
| 1:10–1:40 | Open question 3 | Whether grokking and double descent share a common mechanism or are distinct phenomena |
| 1:40–2:00 | Synthesis | What "progress" would look like for each; current partial answers' real scope |

### Materials/Equipment
- Slides: "Current Open Problems in Neural Network Theory" (instructor-refreshed each offering)
- Instructor-curated current papers/preprints representing each surveyed question's frontier

### Formative Check (in-class)
For one surveyed open question, state what would count as a resolving answer, and what the
strongest current partial answer actually establishes short of that.

### Link to Lab/Assessment
Lab 14: a critical-writing position paper on one of the surveyed open problems (see
`lab-manuals/lab-14.md`). No code required this week.
