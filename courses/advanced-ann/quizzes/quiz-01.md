# Quiz 1 — The NTK Revisited & Mean-Field Theory (Week 3)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of
Quizzes (10%, best 5 of 6 counted)

1. Write the exact function-space ODE $\dot u_t = \ldots$ derived from gradient flow (Week 2 §2),
   and state the two claims about $\Theta_t$ that, together, turn it into kernel gradient descent
   against a fixed kernel. (2 pts)
2. State the lazy-training condition precisely, in terms of $\|\theta_t-\theta_0\|$ and
   $\|\theta_0\|$. (2 pts)
3. Name one output-layer scaling convention that produces the NTK limit and one that produces the
   mean-field limit, and state which one admits feature learning. (2 pts)
4. Using the mean-field variance recursion, state the fixed-point condition on $\sigma_w^2$ for
   plain ReLU, and name the initialization scheme it recovers. (2 pts)
5. A colleague claims: "Since both the NTK limit and the mean-field limit are valid width→∞
   idealizations of the same network, they must agree on whether feature learning occurs." Explain
   what is wrong with this claim. (2 pts)

before the quiz).**
