# Week 1 — Lecture Content: The Statistical Learning Framework

## 1. What This Course Assumes, and What It Adds
*Introduction to Machine Learning* taught you to fit, tune, and evaluate regression, logistic
regression, k-NN, Naive Bayes, decision trees, bagging/boosting ensembles, and kernel SVMs in
scikit-learn, and to evaluate them with cross-validation and the right metrics. This course does
not re-teach any of that. It answers a different question for each of those algorithms: **why**
does it generalize, **how well**, and **under what assumptions** — using the same statistical
machinery (risk, ERM, concentration inequalities, VC dimension, Rademacher complexity, convex
duality, RKHS theory) applied uniformly across all of them.

## 2. The Statistical Learning Setup
Fix an **instance space** $\mathcal{X}$ and a **label space** $\mathcal{Y}$ (e.g.
$\mathcal{Y}=\{-1,+1\}$ for binary classification, $\mathcal{Y}=\mathbb{R}$ for regression). Data
is generated by an unknown **distribution** $D$ over $\mathcal{X}\times\mathcal{Y}$. A **loss
function** $\ell:\mathcal{Y}'\times\mathcal{Y}\to\mathbb{R}_{\geq0}$ scores a prediction against a
true label (e.g. $\ell(\hat y,y)=\mathbb{1}[\hat y\neq y]$ for 0/1 loss, $\ell(\hat y,y)=(\hat
y-y)^2$ for squared loss).

For a hypothesis $h:\mathcal{X}\to\mathcal{Y}'$, define:
- **True (population) risk:** $L_D(h) = \mathbb{E}_{(x,y)\sim D}\big[\ell(h(x),y)\big]$. This is
  what we actually care about and can never compute, because $D$ is unknown.
- **Empirical risk:** given a sample $S=\{(x_1,y_1),\dots,(x_m,y_m)\}$ drawn i.i.d. from $D$,
  $\widehat{L}_S(h) = \frac{1}{m}\sum_{i=1}^m \ell(h(x_i),y_i)$. This is computable, and it is
  what every `.fit()` call in the prerequisite course was minimizing (under some loss).

## 3. The Empirical Risk Minimization (ERM) Principle
Given a **hypothesis class** $H$ (e.g., all linear classifiers, all depth-$k$ decision trees),
the ERM principle picks
$$
\hat h = \arg\min_{h\in H} \widehat{L}_S(h).
$$
This is exactly what `LogisticRegression.fit`, `DecisionTreeClassifier.fit`, and every other
`.fit()` call does (for the corresponding $H$ and $\ell$) — ERM is the formal name for "fit the
model to minimize training loss," and the entire remainder of this course is about understanding
the gap between $\widehat{L}_S(\hat h)$ (what ERM reports) and $L_D(\hat h)$ (what we actually
want to know).

## 4. Why Unrestricted ERM Fails
**Claim:** without restricting $H$, ERM can achieve $\widehat{L}_S(\hat h)=0$ while
$L_D(\hat h)$ is arbitrarily bad. **Argument:** let $H$ be *all* functions
$\mathcal{X}\to\mathcal{Y}$ (no restriction at all). Define $\hat h(x) = y_i$ if $x=x_i$ for some
$i$ in $S$, and $\hat h(x)=$ anything (say, a fixed constant) otherwise. Then
$\widehat{L}_S(\hat h)=0$ exactly, by construction — $\hat h$ perfectly memorizes the sample. But
$\hat h$ makes no use whatsoever of the structure of $D$ outside of $S$, so on a fresh draw from
$D$ it behaves like an arbitrary guess, and $L_D(\hat h)$ can be as bad as random guessing. This
is overfitting, stated as a theorem-shaped fact rather than a practical symptom: **the hypothesis
class $H$ itself, not just the algorithm, must be restricted (or the loss must be regularized) for
ERM to have any hope of generalizing.** Weeks 2–4 make "restricted enough to generalize" precise
via sample complexity, VC dimension, and Rademacher complexity.

## 6. Scope Boundaries Against Sibling Graduate Courses
- **vs. *Artificial Neural Network* (Graduate):** that course treats PAC learning, VC dimension,
  and Rademacher complexity *conceptually*, and only as a lens for discussing why classical
  generalization theory struggles with overparameterized neural networks. **This course builds the
  same tools rigorously and generally** — real definitions, real bounds, real proof sketches, for
  arbitrary hypothesis classes — *before* any such application exists to discuss. This course does
  not cover the Universal Approximation Theorem, backpropagation/autodiff theory, initialization or
  normalization theory, loss-landscape geometry, or the Neural Tangent Kernel; those are owned by
  *Artificial Neural Network*.
- **vs. *Artificial Intelligence* (Graduate):** general exact/approximate inference algorithms for
  probabilistic graphical models and their computational complexity, game theory, MDPs/RL, and
  heuristic search belong entirely to that course. This course's Week 11 (CRFs) briefly contrasts
  discriminative and generative structured models but does not re-teach general PGM inference.
- **vs. the forthcoming *Deep Learning* (Graduate):** deep architectures (CNNs, RNNs,
  Transformers, generative models) are out of scope here entirely.
- **vs. *Introduction to Machine Learning*:** the applied algorithms themselves (how to call
  `RandomForestClassifier`, how to read an ROC curve) are assumed, not retaught; this course
  supplies their theoretical foundations.

## 7. Code: Empirical Risk vs. True Risk for an Unrestricted Hypothesis Class
```python
import numpy as np

def true_concept(x):
    return (x[:, 0] + x[:, 1] > 0).astype(int)

def memorizer_fit(X_train, y_train):
    """H = all functions: memorize the training labels exactly; predict a fixed default
    (here, 0) for any unseen input, including unseen test inputs (even duplicates with noise
    would break this — the point is that memorization carries no information past the sample)."""
    lookup = {tuple(x): y for x, y in zip(X_train, y_train)}
    return lookup

def memorizer_predict(lookup, X):
    return np.array([lookup.get(tuple(x), 0) for x in X])

rng = np.random.default_rng(0)
X_train = rng.normal(size=(200, 2))
y_train = true_concept(X_train)
X_test = rng.normal(size=(2000, 2))     # fresh draws: essentially never collide with X_train
y_test = true_concept(X_test)

model = memorizer_fit(X_train, y_train)
train_err = np.mean(memorizer_predict(model, X_train) != y_train)   # exactly 0 by construction
test_err = np.mean(memorizer_predict(model, X_test) != y_test)      # close to chance

print(f"empirical risk (train): {train_err:.3f}")
print(f"true risk estimate (test): {test_err:.3f}")
```
Expect `train_err = 0.000` exactly and `test_err` near `0.5` (chance level for this balanced
concept) — a direct demonstration that $\widehat{L}_S(\hat h)=0$ guarantees nothing about
$L_D(\hat h)$ once $H$ is unrestricted.
