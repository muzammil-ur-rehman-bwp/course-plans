# Week 16 Lecture Plan — Machine Learning (Graduate)
## Topic: Capstone Research Presentations + Course Review

**Duration:** 2 hours lecture/presentations + 3 hour presentation session

### Learning Objectives (Bloom's Level)
1. Present an original research-style capstone project in a conference-talk format. (*Create*)
2. Critically evaluate peers' capstone presentations using the Week 15 reading framework. (*Evaluate*)
3. Recall and synthesize the full 16-week course map. (*Remember, Understand*)
4. Map this course's foundations onto the sibling graduate ANN/AI/DL courses. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–2:00 | Capstone presentations | Student talks + Q&A (lecture slot) |
| 2:00–3:30 | Capstone presentations (continued) | Student talks + Q&A (lab slot) |
| 3:30–4:00 | Course review | Full course-map recap; connections to sibling graduate courses |
| 4:00–4:30 | Final exam preview | Format, emphasis (Weeks 9–15), sample questions |

### Materials/Equipment
- Projector/screen for all student presentations
- Course-map summary slide

### Formative Check (in-class)
Each student states, in one sentence, which single course result was most load-bearing for their
capstone.

### Link to Lab/Assessment
No new lab this week (capstone presentations in place of a lab). **Capstone project final
submission + presentation due.** Final Exam next week (Week 17).
