# Week 15 Lecture Plan — Machine Learning (Graduate)
## Topic: Research Methods and Project Work Session

**Duration:** 2 hours lecture + 3 hour lab/work session

### Learning Objectives (Bloom's Level)
1. Apply a critical framework for reading a theoretical ML paper's claims and assumptions. (*Analyze, Evaluate*)
2. Identify when a stated bound is vacuous at the scale it is being applied to. (*Evaluate*)
3. Apply reproducibility best practices to a theory-adjacent empirical claim. (*Apply*)
4. Progress the capstone project toward its Week 16 presentation. (*Create*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | Reading a theory paper | The five-question critical framework |
| 0:30–0:50 | Reproducibility practices | Seeds, trial counts, toy-experiment-vs-claim gaps |
| 0:50–1:00 | Break | — |
| 1:00–1:15 | Paper Critique presentations (batch 1) | Short in-class presentations + Q&A |
| 1:15–3:00 | Structured capstone work session | Instructor-guided work time, pair/group feedback |

### Materials/Equipment
- Projector for student Paper Critique presentations
- Capstone proposal/rubric handouts for reference during work session

### Formative Check (in-class)
Students apply the five-question framework to the Week 3 VC bound and state the $m$-range over
which it is non-vacuous.

### Link to Lab/Assessment
Lab 15: structured capstone work session (no new lab topic); progress checklist reviewed with
instructor. **Paper Critique & Presentation** due this week.
