## Questions
1. **(McCulloch-Pitts, 10 pts)** Find fixed weights and a threshold that realize a 3-input
   majority function (output 1 if at least 2 of the 3 binary inputs are 1) using a single
   McCulloch-Pitts neuron. Print the full 8-row truth table generated by your neuron and confirm
   it matches the majority function.
2. **(Perceptron, 20 pts)** Using your perceptron implementation from Lab 2, train on a provided
   linearly separable dataset `assignment01_linsep.csv` (2 features, binary label). Report the
   final weights/bias and the number of epochs to converge. Then attempt training on
   `assignment01_xor.csv`; plot misclassifications vs. epoch for 200 epochs and explain, citing
   linear separability, why it never reaches zero.
3. **(Activation functions, 20 pts)** Implement sigmoid, tanh, and ReLU with their derivatives
   (if not reusing Lab 3 code). For $z = -3, -1, 0, 1, 3$, tabulate each function's output and
   derivative. Identify which function has the smallest derivative magnitude at $z=3$ and explain
   the implication for training a deep network.
4. **(MLP forward pass, 30 pts)** Implement `forward_pass` (general, arbitrary depth, if not
   reusing Lab 4 code). Build a 3-layer network (2 inputs → 4 hidden units, ReLU → 3 hidden units,
   ReLU → 1 output, sigmoid) with weights of your choosing (random is fine). Compute and print the
   output for 3 different input vectors, showing the intermediate $z$ and $a$ at every layer for
   one of them.
5. **(Reflection, 20 pts)** In 5–7 sentences, explain in your own words why a single perceptron's
   limitation on XOR is resolved by an MLP, connecting this to the Universal Approximation Theorem
   and its caveats.
