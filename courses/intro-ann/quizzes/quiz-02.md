# Quiz 2 — Loss Functions & Gradient Descent (Week 6)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. Write the formula for binary cross-entropy loss given a sigmoid output $\hat y$ and true label
   $y$. (2 pts)
2. Why does pairing MSE with a saturating sigmoid output cause slow learning on confidently wrong
   predictions, while cross-entropy does not? (2 pts)
3. Write the gradient descent update rule, defining every symbol. (2 pts)
4. What happens to training if the learning rate is set far too high? Describe the observable
   symptom in the loss curve. (2 pts)
5. Explain, in one or two sentences, why training data must be shuffled before each epoch of
   mini-batch or stochastic gradient descent. (2 pts)

before the quiz).**
