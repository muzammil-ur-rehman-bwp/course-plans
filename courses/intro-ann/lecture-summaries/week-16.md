# Week 16 Summary — Capstone Presentations, Course Review

**Key takeaways:**
- The course's full arc: a single neuron's limitation (Wk 1–2) → the MLP's representational fix
  (Wk 3–4) → a matched loss and the chain rule (Wk 5–7) → a working, trained implementation
  (Wk 8) → reliable training in practice (Wk 9–11) → framework-automated scaling (Wk 12) → two
  structured architecture families, CNNs and RNNs (Wk 13–14) → one unified evaluation lens
  (Wk 15).
- Capstone projects demonstrate this full arc end-to-end: a trained network, on real data, with a
  required ablation/comparison experiment analyzed honestly.
- This course's necessarily brief CNN/RNN treatment is a foundation for a dedicated Deep Learning
  course; its neural-network-specific foundations also support a Machine Learning course's
  broader toolkit.

**You should now be able to:** explain, end to end, how a neural network is built, trained, and
evaluated, from a single perceptron through a modern framework-trained CNN or RNN; present and
defend an original neural network project.

**Course complete.** The final exam (Week 17) is comprehensive, with emphasis on Weeks 9–16 per
the assessment plan.
