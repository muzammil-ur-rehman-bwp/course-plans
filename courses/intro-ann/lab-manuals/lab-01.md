# Lab Manual 1 — Environment Setup & the McCulloch-Pitts Neuron

**Duration:** 3 hours | **Prerequisite:** Week 1 lecture

## Objectives
Set up the course Python/NumPy environment and implement a McCulloch-Pitts (MP) neuron that
realizes basic logic gates.

## Setup
Install Python 3.10+, NumPy, and Matplotlib (via `pip` or `conda`); confirm Jupyter/Colab access.
Create `lab01.ipynb`.

## Procedure
1. **Task A — Environment check:** in a notebook cell, print the Python and NumPy versions; create
   and print a small NumPy array to confirm the environment works.
2. **Task B — MP neuron function:** implement `mp_neuron(x, w, theta)` as shown in lecture.
3. **Task C — Logic gates:** using `mp_neuron`, find weights/thresholds that realize AND, OR, and
   NOT; print a truth table for each gate generated entirely by your function (not hard-coded
   outputs).
4. **Task D — NAND:** find weights/threshold for NAND (NOT AND) and print its truth table.
   Note in a markdown cell that NAND is functionally complete (any logic circuit can be built from
   NAND gates alone) — a fact you will revisit when discussing network expressiveness later in the
   course.

## Expected Output
A notebook with Tasks A–D, each producing a printed truth table generated by `mp_neuron`.

## Submission
Submit `lab01.ipynb` by the end of the lab session.
