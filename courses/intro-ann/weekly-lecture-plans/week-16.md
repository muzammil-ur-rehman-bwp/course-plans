# Week 16 Lecture Plan — Introduction to Artificial Neural Networks
## Topic: Capstone Presentations, Course Review

**Duration:** 2 hours lecture + 3 hour lab (both sessions used for presentations)

### Learning Objectives (Bloom's Level)
1. Evaluate peers' capstone projects, including their ablation/comparison experiments. (*Evaluate*)
2. Create and deliver a clear presentation of an original neural network project. (*Create*)
3. Synthesize the full course map, from the McCulloch-Pitts neuron through CNNs and RNNs, into a
   single coherent narrative. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Course map recap | One slide tracing perceptron → MLP → backprop → optimizers/regularization → frameworks → CNN/RNN → evaluation |
| 0:10–1:50 | Capstone presentations | 5–7 minutes + Q&A per student/pair (schedule depends on enrollment; lab session continues presentations if needed) |
| 1:50–2:00 | Course wrap-up | Where this course leads: Machine Learning, Deep Learning, and advanced architecture courses |

### Materials/Equipment
- Presentation schedule/sign-up sheet
- Projector/screen-sharing for student presentations

### Formative Check (in-class)
Each student submits one written question or comment for at least two other presentations,
collected as informal peer feedback (not graded, but encouraged for engagement).

### Link to Lab/Assessment
No new lab this week; the lab session is used to continue/complete capstone presentations if the
lecture slot alone is insufficient. Capstone project final submission due.
