# Week 16 Lecture Plan — Object Oriented Programming (C++)
## Topic: Capstone Presentations; Course Review

**Duration:** 2 hours lecture (presentations) + 3 hour lab (presentations continued / final submission support)

### Learning Objectives (Bloom's Level)
1. Evaluate peers' capstone designs and implementations against the course's OOP principles. (*Evaluate*)
2. Create and deliver a presentation of an original C++ program integrating inheritance, polymorphism, templates/STL, and exception handling. (*Create*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:40 | Capstone presentations | 5–7 minutes per student/pair + Q&A (schedule depends on enrollment; may extend into lab) |
| 1:40–1:55 | Course review | Recap of the course map: encapsulation → constructors/destructors → operator overloading → composition → inheritance → polymorphism → templates → exceptions → STL → design → RAII/smart pointers |
| 1:55–2:00 | Looking ahead | Brief look ahead to Data Structures & Algorithms and other follow-on courses |

### Materials/Equipment
- Presentation schedule and room/projector setup
- Capstone rubric (`assignments/capstone-rubric.md`) for instructor scoring during presentations

### Formative Check (in-class)
During Q&A, each presenter should be able to point to the specific line(s) of their own code
where inheritance, polymorphism, and exception handling are each used — a direct, informal check
of whether the integration (not just the presence) of these concepts is understood.

### Link to Lab/Assessment
No new lab this week — lab time supports final capstone presentations/submission.
**Capstone project final submission + presentation due this week.**
