# Week 16 Summary — Capstone Presentations; Course Review

**Key takeaways:**
- The semester moved from encapsulation through construction/destruction, operator overloading,
  composition, inheritance, polymorphism, templates, exceptions, the STL, software design, and
  finally RAII/smart pointers — each topic building directly on the ones before it.
- The five ideas worth carrying forward precisely: virtual destructors, object slicing, the Rule
  of Three (and its smart-pointer resolution), composition-vs-inheritance as a design choice, and
  abstract classes as C++'s interface convention.
- The capstone project was each student's chance to integrate inheritance, polymorphism,
  templates/STL, and exception handling in one original program.

**You should now be able to:** design, build, and explain a C++ program that correctly combines
encapsulation, inheritance, polymorphism, generic programming, and exception handling — and
articulate, concept by concept, why each subtle rule (virtual destructors, slicing, Rule of
Three) exists.

**Next steps:** this course's class-design foundation feeds directly into Data Structures &
Algorithms and other follow-on courses, which build custom data structures using the same tools.
