# Lab Assignment 1 — Encapsulation (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab01.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-01.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (`Temperature` class, validated, `const` getter) | 2 |
| Task B correct (`Rectangle` class, validated constructor and setters, `const` methods) | 3 |
| Task C correct (clear, accurate `protected` justification) | 2 |
| Task D correct (`isSquare` using only the public interface) | 3 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `g++ -std=c++17 -Wall`.
- Data members must remain `private`; full credit requires validation inside the class, and
  correct, consistent use of `const` on non-mutating methods.
