# Week 6 Summary — Algorithmic Game Theory I: Equilibrium Computation

**Key takeaways:**
- Zero-sum two-player Nash equilibria are polynomial-time computable via linear programming
  (the minimax theorem).
- Computing a Nash equilibrium of a general (non-zero-sum) game is PPAD-complete — a kind of
  hardness distinct from NP-completeness, reflecting Nash's non-constructive fixed-point
  existence proof.
- Correlated equilibria, by contrast, are polynomial-time computable via linear programming for
  any number of players.

**You should now be able to:** explain what PPAD-completeness means and why it differs from
NP-completeness; compute Nash and correlated equilibria for small games.
