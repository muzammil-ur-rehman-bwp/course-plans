# Week 11 Summary — Foundational and Philosophical Debates I

**Key takeaways:**
- The symbol grounding problem (Harnad, 1990) asks how a system's symbols acquire meaning
  connected to the world, not just to other symbols within the same system — a question that
  resurfaces for learned, data-driven representations, not only hand-built symbolic ones.
- The frame problem (McCarthy & Hayes, 1969) asks how to represent action effects tractably
  without explicitly enumerating every non-effect — a problem any compact state representation
  (an MDP's transition model, a world model) is implicitly answering.
- Both are treated as live, technically grounded research questions, not historical trivia.

**You should now be able to:** state both problems precisely in their original terms; identify
which design choices in a modern system function as implicit (and possibly unsatisfying) answers
to each.
