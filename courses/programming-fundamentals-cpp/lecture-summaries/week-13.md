# Week 13 Summary — Intro to Classes

**Key takeaways:**
- `class` defaults to `private` access; `struct` defaults to `public` — otherwise they are
  nearly identical in C++.
- Encapsulation (private data + public methods) lets a class enforce its own rules every time its
  data changes, rather than trusting every caller to do so correctly.
- A constructor runs automatically when an object is created and is the natural place to validate
  and initialize state.
- This is a preview, not full OOP — inheritance and polymorphism are covered in the dedicated
  Object-Oriented Programming course that follows this one.

**You should now be able to:** design a simple class with private data, a constructor, and public
accessor/mutator methods; explain why encapsulation matters.
