# Week 5 Summary — Functions

**Key takeaways:**
- Functions decompose a program into named, reusable, testable pieces; a function declaration
  lets other code call it before the compiler sees the definition.
- Pass-by-value gives a function a copy of the argument (changes don't affect the caller);
  pass-by-reference (`&`) gives the function direct access to the caller's variable.
- Default arguments let a parameter be omitted at some call sites; overloading lets several
  functions share a name as long as their parameter lists differ.
- Local variables exist only within their declaring function/block.

**You should now be able to:** write functions with value and reference parameters; explain when
each is needed; write and call overloaded functions.
