# Week 1 Summary — Intro to Programming & C++ Basics

**Key takeaways:**
- A C++ program must be compiled and linked into an executable before it can run; always compile
  with `-Wall` to catch likely bugs early.
- `#include <iostream>`, `int main()`, `std::cout`, and `std::cin` are the skeleton of every
  console program we write this semester.
- C++ is statically typed: `int`, `double`, `char`, and `bool` are the core primitive types, each
  with a fixed size and meaning.
- Always initialize variables at declaration — reading an uninitialized variable is undefined
  behavior, not just "probably zero."

**You should now be able to:** compile and run a C++ program from the command line; declare and
initialize variables of primitive types; read values with `std::cin` and print results with
`std::cout`.
