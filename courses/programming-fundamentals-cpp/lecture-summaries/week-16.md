# Week 16 Summary — Capstone Presentations & Course Review

**Key takeaways:**
- The capstone project is the semester's synthesis: arrays/structs for data, functions for
  organization, and file I/O for persistence, applied to one original problem.
- The course's 16 weeks form a dependency chain, not a list of unrelated topics — each later
  concept reused an earlier one directly.
- Encapsulation (Week 13) and informal algorithm efficiency (Week 14) are direct previews of the
  Object-Oriented Programming and Data Structures & Algorithms courses that follow.

**You should now be able to:** present and defend the design of an original C++ console program;
trace how any given week's topic depends on earlier material; identify what the next two courses
in the sequence will build on top of this one.

**Course complete.** Final exam covers Weeks 9–16 with heavier weighting, per the Assessment
Plan in `course-plan.md`.
