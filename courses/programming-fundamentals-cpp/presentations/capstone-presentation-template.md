# Capstone Presentation Template (Student-Facing)

**Target length:** 5–7 minutes + Q&A | **Given to students in Week 11 alongside the proposal
guidelines, used for the Week 16 presentation.**

## Required Slides
1. **Title** — project name, your name(s).
2. **Problem statement** — what does your console application manage, and why does it matter?
3. **Data design** — which struct(s) and array(s) represent your data (a short code snippet or
   diagram is encouraged).
4. **Core operations** — which functions you implemented (add/remove/search/update/report) and
   how they fit together.
5. **Persistence** — how your program saves and loads its data with file I/O.
6. **Demo** — a live or recorded demonstration of the program working end-to-end.
7. **Limitations & next steps** — one honest limitation and what you'd try with more time.
8. **Questions** — invite audience questions.

## Presentation Tips
- Practice the timing — 5–7 minutes goes faster than it sounds; cut detail, not clarity.
- Lead with the problem, not the code — the audience needs to care about the "why" before the
  "how."
- Show the program actually running early; a working demo is worth more than a slide describing
  one.
- Be honest about what didn't work — the rubric (`assignments/capstone-rubric.md`) explicitly
  rewards sound, safe code over simply claiming every feature works.
