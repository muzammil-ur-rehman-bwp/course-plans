# Week 1 Lecture Plan — Programming Fundamentals (C++)
## Topic: Intro to Programming & C++ Basics

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall what a program is and describe the compile-link-run model. (*Remember*)
2. Explain the role of `#include`, `main`, `std::cout`, and `std::cin` in a minimal C++ program. (*Understand*)
3. Write and compile a simple C++ program that declares variables of primitive types and performs basic I/O. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Course intro | Syllabus walkthrough, grading, capstone preview |
| 0:10–0:30 | What is a program? | Compile → link → run model; live demo compiling with `g++` |
| 0:30–1:00 | First C++ program | Live-coded demo: `#include <iostream>`, `main`, `std::cout` |
| 1:00–1:40 | Variables & primitive types | Live-coded demo: `int`, `double`, `char`, `bool`; declaration/initialization |
| 1:40–2:00 | Basic I/O | Live-coded demo: `std::cin >>`, reading user input |

### Materials/Equipment
- Slides: "Compiling Your First C++ Program"
- Live-coding environment (VS Code + terminal)
- Handout: C++ syntax quick-reference cheat sheet

### Formative Check (in-class)
Quick exercise: write a program that declares an `int` and a `double`, reads both from the user,
and prints their sum.

### Link to Lab/Assessment
Lab 1: Compiling and running basic C++ programs (see `lab-manuals/lab-01.md`). No graded
assignment this week.
