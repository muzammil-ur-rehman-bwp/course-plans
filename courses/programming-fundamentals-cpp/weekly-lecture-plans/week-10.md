# Week 10 Lecture Plan — Programming Fundamentals (C++)
## Topic: Structs

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall `struct` definition and member-access syntax. (*Remember*)
2. Explain when a struct is a better fit than several parallel arrays. (*Understand*)
3. Build and process an array of structs representing real-world records. (*Apply, Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Why structs? | Parallel-arrays problem; motivating a grouped record |
| 0:25–0:55 | Defining & using a struct | Live-coded demo: a `Student` struct |
| 0:55–1:25 | Arrays of structs | Live-coded demo: an array of `Student` records |
| 1:25–1:50 | Structs & functions | Pass-by-value vs. pass-by-reference for structs |
| 1:50–2:00 | Practice problem | Design a struct for a given scenario |

### Materials/Equipment
- Slides: "Structs: Grouping Related Data"
- Live-coding environment (VS Code + terminal)

### Formative Check (in-class)
Design a `struct Book` with fields for title, author, and price, then write a function that
prints a `Book` passed by `const` reference.
