# Week 6 Lecture Plan — Programming Fundamentals (C++)
## Topic: Arrays (1D)

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall array declaration, initialization, and indexing syntax. (*Remember*)
2. Explain why C++ performs no automatic bounds checking on raw arrays. (*Understand*)
3. Write functions that process an array (and its size) passed as parameters. (*Apply, Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Array basics | Declaration, initialization, indexing |
| 0:25–0:55 | Iterating over arrays | Live-coded demo: sum, max, min, average |
| 0:55–1:25 | Arrays & functions | Live-coded demo: passing an array + size to a function |
| 1:25–1:50 | Bounds & pitfalls | Out-of-bounds access, undefined behavior demo |
| 1:50–2:00 | `std::array` mention | Brief comparison to raw arrays |

### Materials/Equipment
- Slides: "Arrays: Storing Collections of Data"
- Live-coding environment (VS Code + terminal)

### Formative Check (in-class)
Given `int scores[5] = {90, 85, 70, 60, 95};`, write the loop that finds the index of the highest
score.
