# Week 4 Lecture Plan — Programming Fundamentals (C++)
## Topic: Loops — `for`, `while`, `do-while`

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the syntax of `for`, `while`, and `do-while` loops. (*Remember*)
2. Explain the difference between counter-controlled and sentinel-controlled loops. (*Understand*)
3. Write loops that correctly accumulate, count, or search over repeated input, avoiding off-by-one and infinite-loop errors. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | The `for` loop | Live-coded demo: counting, accumulating a sum |
| 0:25–0:50 | The `while` loop | Live-coded demo: sentinel-controlled input loop |
| 0:50–1:10 | The `do-while` loop | Live-coded demo: menu that runs at least once |
| 1:10–1:35 | `break`/`continue`; nested loops | Live-coded demo: multiplication table |
| 1:35–2:00 | Practice problems | Paired exercise: convert between loop forms |

### Materials/Equipment
- Slides: "Repetition in C++: Loop Forms Compared"
- Live-coding environment (VS Code + terminal)

### Formative Check (in-class)
Trace by hand how many times each loop body executes for a given `for`, `while`, and `do-while`
example with the same bounds; identify which one runs a different number of times and why.
