# Week 7 Lecture Plan — Programming Fundamentals (C++)
## Topic: 2D Arrays and Strings

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall 2D array declaration and indexing, and the difference between a C-string and `std::string`. (*Remember*)
2. Explain row-major layout and why `std::string` is preferred over C-strings in modern C++. (*Understand*)
3. Write nested-loop code that processes a 2D array and code that manipulates `std::string` values. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | 2D array basics | Declaration, indexing, nested-loop traversal |
| 0:30–0:55 | 2D array processing | Live-coded demo: row/column sums |
| 0:55–1:20 | C-strings | `char[]`, null terminator, `<cstring>` functions (`strlen`, `strcmp`) |
| 1:20–1:50 | `std::string` | Concatenation, indexing, `substr`, `find`, comparison |
| 1:50–2:00 | Comparison & recommendation | Why prefer `std::string` |

### Materials/Equipment
- Slides: "2D Arrays and Strings in C++"
- Live-coding environment (VS Code + terminal)

### Formative Check (in-class)
Given a 3x3 `int` matrix, write the nested loop that computes the sum of each row.
