# Week 13 Lecture Plan — Programming Fundamentals (C++)
## Topic: Intro to Classes

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the `class` keyword, access specifiers, and constructor syntax. (*Remember*)
2. Explain encapsulation and why private data with public accessor/mutator methods is preferred over public fields. (*Understand*)
3. Design and implement a simple class with private data, a constructor, and public methods. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | From struct to class | `struct` vs. `class`; default access difference |
| 0:20–0:50 | Encapsulation | Private data, public accessors/mutators; motivating example |
| 0:50–1:25 | Constructors | Live-coded demo: a `Rectangle` or `BankAccount` class |
| 1:25–1:50 | Member functions | Methods that operate on an object's own data |
| 1:50–2:00 | Looking ahead | One-slide preview of inheritance/polymorphism (OOP course) |

### Materials/Equipment
- Slides: "A First Look at Classes"
- Live-coding environment (VS Code + terminal)

### Formative Check (in-class)
Explain, in one or two sentences, why making all of a class's data `public` defeats the purpose
of encapsulation.
