# Week 12 Lecture Plan — Programming Fundamentals (C++)
## Topic: Recursion

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the two required parts of a recursive function: base case and recursive case. (*Remember*)
2. Explain how recursive calls build and unwind a call stack, using a trace diagram. (*Understand*)
3. Write and trace recursive functions, and compare a recursive solution to its iterative equivalent. (*Apply, Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | What is recursion? | Base case + recursive case; factorial example |
| 0:25–0:55 | Tracing recursion | Live call-stack trace diagram for `factorial(4)` |
| 0:55–1:25 | More examples | Fibonacci, sum of an array, recursive search |
| 1:25–1:50 | Recursion vs. iteration | Trade-offs; stack overflow from a missing/wrong base case |
| 1:50–2:00 | Practice problem | Trace a given recursive function by hand |

### Materials/Equipment
- Slides: "Recursion: Solving Problems in Terms of Themselves"
- Whiteboard/diagram tool for call-stack traces

### Formative Check (in-class)
Trace `factorial(4)` by hand, writing out each call and its return value in order.
