# Week 8 Lecture Plan — Programming Fundamentals (C++)
## Topic: Pointers & References; Midterm Review

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the `&` (address-of) and `*` (dereference) operators and pointer declaration syntax. (*Remember*)
2. Explain the difference between a pointer and a reference. (*Understand*)
3. Write a function that uses a pointer parameter to read or modify a caller's variable, and solve review problems spanning Weeks 1–7. (*Apply, Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Addresses and pointers | Live-coded demo: `&`, `*`, `nullptr` |
| 0:25–0:50 | Pointer arithmetic & arrays | Live-coded demo: pointer-based array traversal |
| 0:50–1:10 | Pointers vs. references | Side-by-side comparison table and examples |
| 1:10–2:00 | Midterm review | Practice problems spanning Weeks 1–7 |

### Materials/Equipment
- Slides: "Pointers and References in C++"
- Midterm review problem set (practice, ungraded)

### Formative Check (in-class)
Given `int x = 5; int* p = &x;`, predict the output of `*p`, `p`, and `&x`, and explain which
values are equal and which are different kinds of thing (address vs. value).
