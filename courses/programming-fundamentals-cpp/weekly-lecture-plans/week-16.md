# Week 16 Lecture Plan — Programming Fundamentals (C++)
## Topic: Capstone Presentations & Course Review

**Duration:** 2 hours lecture + 3 hour lab (both periods used for presentations)

### Learning Objectives (Bloom's Level)
1. Present and explain an original capstone console application to an audience. (*Create, Evaluate*)
2. Evaluate peers' projects against the course's technical standards (correctness, memory safety, design). (*Evaluate*)
3. Recall and connect the full semester's topic sequence as a coherent whole. (*Remember, Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:30 | Capstone presentations | 5–7 min per student/pair + brief Q&A (see schedule) |
| 1:30–1:50 | Course review | Recap: basics → control flow → functions → arrays/strings → pointers → dynamic memory → structs → file I/O → recursion → classes → algorithms |
| 1:50–2:00 | Looking ahead | Preview: Object-Oriented Programming and Data Structures & Algorithms courses |

### Materials/Equipment
- Presentation schedule/sign-up sheet
- Projector/screen for student demos
- Slides: "Course Review — Programming Fundamentals"

### Formative Check (in-class)
Peer evaluation: each student notes one strength and one suggestion for two other projects.

### Link to Lab/Assessment
No new lab this week — lab time is used for capstone presentations. Final capstone submission
and presentation are graded per `assignments/capstone-rubric.md`.
