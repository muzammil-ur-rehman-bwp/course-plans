# Week 3 Lecture Plan — Programming Fundamentals (C++)
## Topic: Control Flow — `if`/`else`, `switch`

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the syntax of `if`/`else if`/`else` and `switch` statements. (*Remember*)
2. Explain how nested conditionals and `switch` fall-through affect program behavior. (*Understand*)
3. Translate a decision table or problem description into correct branching code. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | `if`/`else` basics | Live-coded demo: grading-scale example |
| 0:25–0:50 | Nested & chained conditionals | Live-coded demo: `else if` ladders; the dangling-`else` trap |
| 0:50–1:20 | The `switch` statement | Live-coded demo: menu selection; `break` and fall-through |
| 1:20–1:45 | Ternary operator | Short-form conditional expressions |
| 1:45–2:00 | Practice problems | Paired exercise: decision table → code |

### Materials/Equipment
- Slides: "Branching in C++"
- Live-coding environment (VS Code + terminal)

### Formative Check (in-class)
Given a decision table (score → letter grade), write the `if`/`else if` chain that implements it,
then rewrite the same table using `switch` on a derived grade-band integer.
