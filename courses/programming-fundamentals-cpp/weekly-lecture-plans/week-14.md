# Week 14 Lecture Plan — Programming Fundamentals (C++)
## Topic: Sorting & Searching Algorithms

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the steps of bubble sort, selection sort, linear search, and binary search. (*Remember*)
2. Explain why binary search requires a sorted array and how it eliminates half the remaining elements each step. (*Understand*)
3. Implement all four algorithms on arrays and compare their relative efficiency informally. (*Apply, Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | Linear search & bubble sort | Live-coded demo: trace on a small array |
| 0:30–1:00 | Selection sort | Live-coded demo: trace on the same array |
| 1:00–1:35 | Binary search | Live-coded demo: trace on a sorted array; why sortedness matters |
| 1:35–1:55 | Efficiency intuition | Comparison counts; informal Big-O intuition |
| 1:55–2:00 | Wrap-up | When to choose which algorithm |

### Materials/Equipment
- Slides: "Sorting & Searching on Arrays"
- Whiteboard for step-by-step trace diagrams

### Formative Check (in-class)
Trace selection sort by hand on `[5, 2, 8, 1]`, writing the array state after each pass.
