# Week 9 Lecture Plan — Programming Fundamentals (C++)
## Topic: Midterm Exam + Dynamic Memory

**Duration:** 2 hours lecture + 3 hour lab (exam occupies part of lecture time)

### Learning Objectives (Bloom's Level)
1. Demonstrate recall and application of Weeks 1–8 material under exam conditions. (*Remember, Apply*)
2. Explain the difference between stack and heap memory, and why `new` needs a matching `delete`. (*Understand*)
3. Allocate and free single objects and dynamic arrays correctly with `new`/`delete`. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:00 | **Midterm Exam** | Closed-book/open-notes per instructor policy, covers Weeks 1–8 |
| 1:00–1:10 | Break | — |
| 1:10–1:35 | Stack vs. heap | Conceptual diagram; lifetime differences |
| 1:35–2:00 | `new`/`delete` | Live-coded demo: single object and dynamic array allocation |

### Materials/Equipment
- Midterm exam paper/online quiz
- Slides: "The Heap: Dynamic Memory in C++"

### Formative Check (in-class)
Post-exam discussion: for a given code snippet using `new` without a matching `delete`, identify
the memory leak.
