# Quiz 5 — Structs & File I/O (Week 11)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. By default, are the members of a `struct` public or private? (1 pt)
2. Given `struct Point { int x; int y; };`, write a line of code that declares a `Point` named
   `origin` with both fields initialized to `0` using aggregate initialization. (2 pts)
3. What must you check immediately after opening a file with `ifstream` or `ofstream`, and why?
   (2 pts)
4. What is the difference between reading with `fileStream >> value` and
   `std::getline(fileStream, line)`? (2 pts)
5. In the idiom `while (inFile >> name >> score) { ... }`, what causes the loop to stop? (3 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
