# Quiz 1 — C++ Basics (Week 2)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What are the three stages a C++ source file goes through before it runs? (2 pts)
2. What is wrong with the following code, and what is the safest fix?
   ```cpp
   int total;
   total = total + 5;
   std::cout << total;
   ```
   (2 pts)
3. Give the C++ type you would use to store each of: a person's age, a product's price, a
   single letter grade, and whether a user is logged in. (2 pts)
4. What does `std::cin >> x >> y;` do if the user types `3 4` and presses Enter? (2 pts)
5. Explain, in one sentence, why `-Wall` should be used every time you compile. (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
