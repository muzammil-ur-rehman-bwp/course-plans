# Quiz 4 — 2D Arrays, Strings, Pointers (Week 8)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. Given `int grid[2][3] = {{1,2,3},{4,5,6}};`, what is `grid[1][0]`? (1 pt)
2. Give one concrete advantage of `std::string` over a C-string (`char[]`). (2 pts)
3. Given `int x = 10; int* p = &x;`, what does `*p = 20;` do, and what is the value of `x`
   afterward? (2 pts)
4. Explain the difference between a pointer and a reference in terms of whether each can be
   `nullptr`/unbound and whether each can be reseated to point/refer elsewhere later. (3 pts)
5. What is wrong with this code?
   ```cpp
   int* p;
   std::cout << *p;
   ```
   (2 pts)
