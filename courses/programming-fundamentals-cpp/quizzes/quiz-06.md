# Quiz 6 — Recursion & Intro to Classes (Week 13)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What are the two required parts of every correct recursive function? (2 pts)
2. What specifically goes wrong if a recursive function's base case is missing? (2 pts)
3. By default, are the members of a `class` public or private — and how does this differ from a
   `struct`? (2 pts)
4. What is encapsulation, and why is making all of a class's data `private` a part of it? (2 pts)
5. Given the following, what value does `factorial(3)` return, and why?
   ```cpp
   int factorial(int n) {
       if (n <= 1) return 1;
       return n * factorial(n - 1);
   }
   ```
   (2 pts)

before the quiz).**
