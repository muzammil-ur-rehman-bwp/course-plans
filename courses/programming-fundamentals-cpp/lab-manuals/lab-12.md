# Lab Manual 12 — Recursion

**Duration:** 3 hours | **Prerequisite:** Week 12 lecture

## Objectives
Practice writing and tracing recursive functions, and comparing them to iterative equivalents.

## Setup
Create `lab12.cpp` in your working folder.

## Procedure
1. **Task A — Factorial:** write a recursive `int factorial(int n)`; test it for `n = 0, 1, 5`.
2. **Task B — Sum of digits:** write a recursive `int sumOfDigits(int n)` that returns the sum of
   a non-negative integer's digits (e.g., `sumOfDigits(482)` returns 14).
3. **Task C — Recursive array sum:** write a recursive `int sumArray(const int values[], int
   size)` that sums an array without using a loop.
4. **Task D — Mini-challenge:** write both a recursive and an iterative version of
   `int power(int base, int exponent)` (non-negative exponent), and confirm both give identical
   results for several test cases.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly with
`-Wall`, with each function's base case clearly commented.

## Submission
Submit `lab12.cpp` via the course submission system by the end of the lab session.
