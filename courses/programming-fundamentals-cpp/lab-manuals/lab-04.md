# Lab Manual 4 — Loops: `for`, `while`, `do-while`

**Duration:** 3 hours | **Prerequisite:** Week 4 lecture

## Objectives
Practice all three loop forms, loop control (`break`/`continue`), and nested loops.

## Setup
Create `lab04.cpp` in your working folder.

## Procedure
1. **Task A — Counting loop:** use a `for` loop to print all multiples of 3 between 1 and 100.
2. **Task B — Sentinel loop:** use a `while` loop to read integers until the user enters `0`,
   then print the count and sum of all non-zero numbers entered.
3. **Task C — Menu loop:** use a `do-while` loop to display a 3-option menu (print, square, quit)
   that keeps running until the user chooses quit.
4. **Task D — Mini-challenge:** use nested `for` loops to print a right triangle of asterisks of a
   user-specified height (e.g., height 4 prints 1, then 2, then 3, then 4 asterisks per row).

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly with
`-Wall` and producing correct output, including a test of the "zero entered immediately" edge
case for Task B.

## Submission
Submit `lab04.cpp` via the course submission system by the end of the lab session.
