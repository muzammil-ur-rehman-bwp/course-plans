# Lab Manual 7 — 2D Arrays and Strings

**Duration:** 3 hours | **Prerequisite:** Week 7 lecture

## Objectives
Practice 2D array traversal and `std::string` operations.

## Setup
Create `lab07.cpp` in your working folder.

## Procedure
1. **Task A — Matrix fill & print:** declare a 3x3 `int` matrix, fill it with user input using
   nested loops, and print it in grid form.
2. **Task B — Row/column sums:** write functions that compute and print the sum of each row and
   the sum of each column of the matrix from Task A.
3. **Task C — String basics:** read a full name (with `getline`) and a search substring; print
   the name's length, whether it contains the substring (`find`), and the name in uppercase
   (loop over characters, using `toupper`).
4. **Task D — Mini-challenge:** write `bool isPalindrome(const std::string&)` (case-insensitive)
   and test it on at least three strings, including one palindrome and one non-palindrome.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly with
`-Wall` and producing correct output for all provided test cases.

## Submission
Submit `lab07.cpp` via the course submission system by the end of the lab session.
