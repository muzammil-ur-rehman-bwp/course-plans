# Lab Assignment 11 — File I/O (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab11.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-11.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (write file, checked `is_open()`) | 2 |
| Task B correct (read file, checked `is_open()`, correct loop) | 2 |
| Task C correct (struct array loaded from file, average computed) | 3 |
| Task D correct (sorted roster written back out) | 3 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `g++ -std=c++17 -Wall` and must check file-open success before
  reading/writing.
- Partial credit given for logically sound but buggy attempts; no credit for code that does not
  compile at all.
