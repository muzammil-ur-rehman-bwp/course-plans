# Lab Assignment 12 — Recursion (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab12.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-12.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (recursive factorial) | 2 |
| Task B correct (recursive sum of digits) | 3 |
| Task C correct (recursive array sum, no loop) | 3 |
| Task D correct (recursive + iterative `power`, matching results) | 2 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `g++ -std=c++17 -Wall` and must not infinite-recurse/stack-
  overflow on the grader's test input.
- Partial credit given for logically sound but buggy attempts; no credit for code that does not
  compile at all.
