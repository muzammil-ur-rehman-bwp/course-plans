**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab13.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-13.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (`Rectangle` class with validating constructor) | 2 |
| Task B correct (object usage, including the invalid-dimension case) | 2 |
| Task C correct (`BankAccount` class with validating constructor and methods) | 3 |

## Notes
- Code must compile cleanly with `g++ -std=c++17 -Wall`.
- Data members must remain `private`; full credit requires validation to occur inside the class,
