# Lab Assignment 1 — C++ Basics (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab01.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-01.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (Hello, World compiles & runs) | 1 |
| Task B correct (four typed, initialized variables printed) | 2 |
| Task C correct (area/perimeter from user input) | 4 |
| Task D correct (Celsius-to-Fahrenheit conversion) | 3 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `g++ -std=c++17 -Wall` (warnings are not automatically
  disqualifying but must be justified if not fixed).
- Partial credit given for logically sound but buggy attempts; no credit for code that does not
  compile at all.
