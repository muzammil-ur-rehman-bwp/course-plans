# Lab Assignment 10 — Structs (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab10.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-10.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (single struct define/fill/print) | 2 |
| Task B correct (array of structs, formatted output) | 2 |
| Task C correct (`averageGpa`, `countAbove`) | 3 |
| Task D correct (`raiseGpa` by reference, `findTopStudent` by value) | 3 |
| **Total** | **10** |

## Notes
