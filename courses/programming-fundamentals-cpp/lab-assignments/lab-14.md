# Lab Assignment 14 — Sorting & Searching Algorithms (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab14.cpp` containing working, correct solutions to Tasks A–D from `lab-manuals/lab-14.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (bubble sort) | 2 |
| Task B correct (selection sort) | 2 |
| Task C correct (linear search, found and not-found cases) | 3 |
| Task D correct (binary search on sorted data, comparison count reported) | 3 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `g++ -std=c++17 -Wall`.
- Binary search must be run only on data verified sorted beforehand; running it on unsorted data
  does not earn credit even if it happens to return a correct-looking answer.
