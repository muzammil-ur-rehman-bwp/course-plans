# Week 16 Summary — Capstone Presentations; Course Review

**Key takeaways:**
- The semester's course map runs encapsulation → constructors/`Object` methods → composition →
  static members → inheritance → polymorphism → abstract classes → interfaces → generics →
  exceptions → collections → design → testing, with each week's material depending on the ones
  before it.
- Java's distinguishing OOP semantics, revisited together: no destructors (garbage collection
  instead), no multiple class inheritance (multiple interface implementation instead), methods
  virtual by default, and no object slicing, since Java always passes and assigns references.
- The capstone project was designed to require inheritance/interfaces, generics/collections, and
  exception handling together — the three pillars the course spent the most weeks building.

**You should now be able to:** explain and defend an original Java program's design decisions in
front of an audience, and situate this semester's material relative to Data Structures &
Algorithms and Software Engineering courses ahead.
