# Lab Assignment 12 — Exception Handling (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit your `.java` files containing working, correct solutions to Tasks A–D from
`lab-manuals/lab-12.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (checked exception, correctly declared with `throws`) | 3 |
| Task B correct (unchecked exception, no `throws` needed) | 2 |
| Task C correct (`catch` clauses correctly ordered and functioning) | 3 |
| Task D correct (try-with-resources used correctly, resource closed automatically) | 2 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `javac`.
- The program must not crash (uncaught exception) when run with the provided mixed valid/invalid
  test inputs.
