# Week 16 Lecture Plan — Object Oriented Programming (Java)
## Topic: Capstone Presentations; Course Review

**Duration:** 2 hours lecture (presentations) + 3 hour lab (presentations continued/Q&A)

### Learning Objectives (Bloom's Level)
1. Evaluate peers' capstone designs via structured Q&A. (*Evaluate*)
2. Create and present an original Java program integrating the semester's OOP toolkit. (*Create*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Logistics | Presentation order, timing rules (5–7 min + Q&A per team) |
| 0:10–1:50 | Capstone presentations | Each team presents; audience asks at least one question per team |
| 1:50–2:00 | Course review | Recap of the course map: encapsulation → constructors/`Object` methods → composition → static members → inheritance → polymorphism → abstract classes → interfaces → generics → exceptions → collections → design → testing |

### Materials/Equipment
- Projector/screen for student demos
- `presentations/capstone-presentation-template.md` (given to students in Week 11)
- Capstone rubric (`assignments/capstone-rubric.md`) for live grading

### Formative Check (in-class)
Each audience member identifies, for at least one presented project, which OOP technique
(inheritance, interface, generic type, or exception handling) they would ask about if they were
grading it, and why.

### Link to Lab/Assessment
No new lab this week — lab session used for presentation overflow/Q&A.
**Capstone final submission + presentation due this week.**
**Final Exam next week** (Week 17), comprehensive, emphasis on Weeks 9–16.
