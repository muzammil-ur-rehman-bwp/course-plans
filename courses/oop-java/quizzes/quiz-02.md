# Quiz 2 — Constructors & `Object` Methods (Week 3)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What must be true about the placement of a `this(...)` call inside a constructor? (2 pts)
2. What is wrong with the following, and what would fix it?
   ```java
   public boolean equals(Point other) {
       return x == other.x && y == other.y;
   }
   ```
   (2 pts)
3. Why must `hashCode()` be overridden whenever `equals()` is overridden? (2 pts)
4. What does `@Override` actually do at compile time, and why is it worth writing even when a
   method would compile without it? (2 pts)
5. Why does Java have no destructors, and what mechanism replaces the need for one? (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
