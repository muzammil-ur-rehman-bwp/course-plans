# Quiz 4 — Inheritance I (Week 6)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What does a subclass inherit from its superclass via `extends`? (2 pts)
2. What access level is visible to a subclass's own code but not to unrelated outside code? (2
   pts)
3. What must a subclass constructor do if its superclass has no no-argument constructor, and
   what happens if it doesn't? (2 pts)
4. Why does Java allow a class to `extends` only one superclass? What problem does this avoid
   that multiple class inheritance can cause? (2 pts)
5. Given `class Dog extends Animal`, and `Animal` has a `protected String name` field, can code
   inside `Dog` access `name` directly? Can code in an unrelated class `Trainer` (not a subclass
   of `Animal`) access it directly? (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
