# Quiz 5 — Inheritance II & Polymorphism I (Weeks 6–7)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. Distinguish overriding from overloading in one sentence each. (2 pts)
2. What compile-time benefit does `@Override` provide over leaving it off? (2 pts)
3. Why is every Java instance method "virtual by default," and name the three ways a method can
   opt out of dynamic dispatch. (2 pts)
4. What is the difference between upcasting and downcasting, and which one requires an explicit
   cast? (2 pts)
5. Why does passing a `Dog` object as an `Animal`-typed parameter in Java never "slice" it the
   way a C++ by-value parameter might? (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
