# Quiz 6 — Interfaces (Week 9)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What may an interface declare that a class may not use as actual per-instance state? (2 pts)
2. How many interfaces may a single class `implements`, compared to how many classes it may
   `extends`? (2 pts)
3. How does Java's multiple interface implementation avoid the diamond problem that multiple
   class inheritance can cause in other languages? (2 pts)
4. What is a `default` method, and why was it added to interfaces? (2 pts)
5. Give one concrete reason to choose an abstract class over an interface for a given design, and
   one reason to choose an interface over an abstract class. (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
