# Quiz 3 — Static vs. Instance Members (Week 5)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What is the difference between an instance field and a static field in terms of how many
   copies exist? (2 pts)
2. Why can a static method not directly access an instance field? (2 pts)
3. When does a static field initializer or static initializer block run, relative to object
   construction? (2 pts)
4. What is the purpose of giving a utility class a private constructor? (2 pts)
5. Given a `Student` class with a `private static int instanceCount` incremented in its
   constructor, what would `Student.getInstanceCount()` print if called before any `Student` is
   ever constructed, and why? (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
