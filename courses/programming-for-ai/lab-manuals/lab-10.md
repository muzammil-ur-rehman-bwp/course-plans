# Lab Manual 10 — Regression with scikit-learn

**Duration:** 3 hours | **Prerequisite:** Week 10 lecture

## Objectives
Fit, evaluate, and interpret linear and logistic regression models with scikit-learn.

## Setup
Continue with scikit-learn; create `lab10.ipynb`.

## Procedure
1. **Task A — Linear regression:** fit `LinearRegression` on a provided regression dataset;
   report MSE on the test set; plot predicted vs. actual values.
2. **Task B — Feature scaling:** apply `StandardScaler` correctly (fit on train only); refit and
   compare MSE before/after scaling.
3. **Task C — Logistic regression:** fit `LogisticRegression` on a provided binary classification
   dataset; report test accuracy.
4. **Task D — Interpretation:** for the linear regression model, write 2–3 sentences
   interpreting the largest-magnitude coefficient.

## Expected Output
A notebook with Tasks A–D.

Submit `lab10.ipynb` by the end of the lab session. **Capstone project proposal is also due this
week** — submit separately per `assignments/capstone-proposal-guidelines.md`.
