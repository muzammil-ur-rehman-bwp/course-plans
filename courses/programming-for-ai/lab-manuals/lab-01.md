# Lab Manual 1 — Python Essentials

**Duration:** 3 hours | **Prerequisite:** Week 1 lecture

## Objectives
Practice Python syntax, control flow, and functions by building small, self-contained scripts.

## Setup
1. Create a virtual environment: `python -m venv venv` then activate it.
2. `pip install jupyter`.
3. Launch `jupyter notebook` and create `lab01.ipynb`.

## Procedure
1. **Task A — Variables & Operators:** write expressions computing the area and perimeter of a
   rectangle given `width` and `height` variables.
2. **Task B — Control Flow:** write a function `fizzbuzz(n)` that prints "Fizz"/"Buzz"/"FizzBuzz"/
   the number for 1..n per the classic FizzBuzz rules.
3. **Task C — Functions:** write `is_prime(n)` returning `True`/`False`; use it to print all
   primes below 100.
4. **Task D — Mini-challenge:** write `my_max(values)` without using the built-in `max()`.

## Expected Output
A notebook with four clearly labeled cells/sections (A–D), each producing correct, runnable
output with a one-line comment explaining the approach.

## Submission
Export/submit `lab01.ipynb` via the course submission system by the end of the lab session (or
per instructor-announced deadline).
