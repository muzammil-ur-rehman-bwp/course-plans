# Week 9 Summary — Midterm + Intro to Machine Learning

**Key takeaways:**
- Midterm exam covered Weeks 1–8.
- ML splits into supervised (labeled data: regression/classification), unsupervised (unlabeled:
  clustering/dimensionality reduction), and reinforcement learning (not covered in depth).
- The standard ML workflow: collect → explore/clean → split → train → evaluate → iterate.
- A train/test split (`train_test_split`) is essential — evaluating on training data gives a
  misleadingly optimistic performance estimate.

**You should now be able to:** classify a problem as supervised/unsupervised; perform a
train/test split; describe the end-to-end ML workflow.

**Next week:** regression with scikit-learn — the first supervised learning models of the course.
