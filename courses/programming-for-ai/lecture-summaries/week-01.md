# Week 1 Summary — Python Essentials & the AI Tooling Landscape

**Key takeaways:**
- Python is dynamically typed; core types are `int`, `float`, `str`, `bool`.
- Control flow (`if`/`elif`/`else`, `for`, `while`) and functions (`def`) are the building blocks
  of every algorithm we implement this semester.
- Functions are first-class — they can be passed around like data (important for later ML code).
- The AI/ML Python stack layers as: **NumPy** (arrays/math) → **pandas** (tabular data) →
  **scikit-learn** (classical ML) → **PyTorch/Keras** (deep learning), with **Matplotlib** for
  visualization throughout.
- Typical AI pipeline: load → explore → preprocess → train → evaluate → iterate.

**You should now be able to:** write a Python function with conditionals/loops; name the major
AI/ML libraries and what each is for; run a Jupyter notebook.

**Next week:** Python data structures (lists/dicts/sets) and basic OOP, which we'll reuse to
build search-algorithm data structures later in the course.
