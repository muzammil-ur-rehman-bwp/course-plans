# Week 2 Summary — Data Structures & OOP in Python

**Key takeaways:**
- Lists/tuples/sets/dicts differ in ordering, mutability, and typical AI use (e.g., sets for
  "visited" tracking in search, dicts for adjacency lists).
- Comprehensions are the idiomatic, often faster way to build lists/dicts from iterables.
- OOP basics (`class`, `__init__`, `self`, methods, inheritance) let us package state + behavior
  together — this is exactly the pattern scikit-learn and PyTorch use for models.
- We built a reusable `Graph`/`GraphNode` class that Week 5's search labs will build on directly.

**You should now be able to:** choose the right built-in data structure for a task; write a
comprehension; define a simple class with methods.
