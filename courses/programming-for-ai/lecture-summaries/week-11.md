# Week 11 Summary — Classification & Model Evaluation Metrics

**Key takeaways:**
- k-NN classifies by majority vote among nearest neighbors; `k` controls the overfitting/
  underfitting tradeoff.
- Decision Trees split on the most discriminative feature/threshold; SVMs maximize the margin
  between classes and can use kernels for non-linear boundaries.
- Accuracy can be misleading on imbalanced data — precision, recall, and F1 give a fuller picture,
  summarized via the confusion matrix.
- ROC/AUC evaluates classifier performance across all thresholds, not just one.

**You should now be able to:** train and compare multiple classifiers; choose and compute the
right evaluation metric for a given problem; read a confusion matrix and classification report.
