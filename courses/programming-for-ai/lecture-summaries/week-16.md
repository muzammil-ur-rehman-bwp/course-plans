# Week 16 Summary — Capstone, Course Review, AI Ethics

**Key takeaways:**
- The course progressed: Python/data skills → classical AI (search/CSP/probability) →
  statistical ML → neural networks → capstone synthesis, with each phase reusing tools from
  earlier phases.
- Capstone projects demonstrate the ability to frame a problem, apply course techniques
  end-to-end, and evaluate/communicate results (*Create* and *Evaluate* on Bloom's Taxonomy).
- AI ethics: watch for bias/fairness issues from training data, respect data privacy, and use
  AI-generated code responsibly and with understanding, not as an unexamined substitute for your
  own analysis.
