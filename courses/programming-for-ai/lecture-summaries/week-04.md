# Week 4 Summary — pandas & Exploratory Data Analysis

**Key takeaways:**
- `DataFrame`/`Series` are pandas' table and column abstractions; `loc`/`iloc` index by label vs.
  position, boolean masks filter rows.
- `groupby`, `merge`, and missing-data handling (`isna`, `fillna`/`dropna`) are the core data
  wrangling operations you'll reuse all semester.
- EDA (inspect → clean → visualize → summarize) is a mandatory first step before any modeling —
  it determines what preprocessing and model choices make sense later.

**You should now be able to:** load, clean, filter, group, and merge tabular data; run a basic
EDA pass on a new dataset.
