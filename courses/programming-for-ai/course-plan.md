# Course Plan: Programming for Artificial Intelligence

## 1. Course Information

| Field | Detail |
|---|---|
| Course Title | Programming for Artificial Intelligence |
| Level | Undergraduate (3rd/4th year, BS Computer Science / Software Engineering / AI) |
| Credit Hours | 3 (2 hrs lecture + 1 lab session of 3 hrs/week) |
| Prerequisites | Programming Fundamentals, Data Structures & Algorithms, Discrete Mathematics / Linear Algebra (recommended) |
| Programming Language | Python 3.x |
| Core Libraries | NumPy, pandas, Matplotlib, scikit-learn, PyTorch (or TensorFlow/Keras), NLTK/spaCy (intro) |
| Duration | 16 teaching weeks (1 semester) + 1 week buffer/review + exam weeks |
| Delivery Mode | Lecture + Lab (hands-on, Jupyter/Colab based) |

## 2. Course Description

This course introduces students to Python as the primary language for building Artificial
Intelligence systems. It bridges general-purpose programming skills with the data structures,
libraries, and algorithmic thinking required for AI/ML work. Students progress from Python
fundamentals and scientific computing (NumPy/pandas) through classical AI search and knowledge
representation, into applied machine learning and an introduction to neural networks. The course
is lab-intensive: every lecture topic is paired with a hands-on lab that produces working code.

## 3. Goals

- Build fluency in Python as a language for AI/ML development (not just general scripting).
- Develop the ability to represent problems computationally (data structures, state spaces,
  vectorized data) in ways suited to AI algorithms.
- Expose students to the classical (symbolic/search-based) and modern (statistical/learning-based)
  pillars of AI.
- Produce portfolio-ready lab work and a capstone mini-project.

## 4. Course Learning Outcomes (CLOs) — Mapped to Bloom's Taxonomy

| CLO | Statement | Bloom's Level(s) |
|---|---|---|
| CLO1 | Recall and explain core Python syntax, data structures, and the Python AI/ML ecosystem. | Remember, Understand |
| CLO2 | Use NumPy and pandas to manipulate, clean, and vectorize data for AI pipelines. | Apply |
| CLO3 | Analyze problems to choose an appropriate search, representation, or learning technique. | Analyze |
| CLO4 | Implement classical AI algorithms (search, constraint satisfaction, simple planning) in Python. | Apply, Analyze |
| CLO5 | Build, train, and evaluate machine learning models using scikit-learn. | Apply, Evaluate |
| CLO6 | Design and implement a basic neural network (forward/backward pass) and justify architecture choices. | Analyze, Evaluate, Create |
| CLO7 | Design, build, and present an original AI mini-project that solves a real or simulated problem. | Create, Evaluate |

### Bloom's Taxonomy progression across the semester

The course is deliberately sequenced to move students up Bloom's cognitive levels:

| Phase | Weeks | Dominant Bloom's Levels | Focus |
|---|---|---|---|
| Foundation | 1–4 | Remember, Understand, Apply | Python core, NumPy/pandas |
| Core AI Techniques | 5–9 | Apply, Analyze | Search, CSP, probability, intro ML |
| Applied ML | 10–13 | Apply, Analyze, Evaluate | Supervised/unsupervised learning, model evaluation |
| Synthesis | 14–16 | Evaluate, Create | Neural networks, capstone mini-project |

## 5. Weekly Topic Overview (16 Weeks)

| Week | Topic | Bloom's Focus |
|---|---|---|
| 1 | Python essentials: syntax, control flow, functions, the AI/ML tooling landscape | Remember, Understand |
| 2 | Data structures in Python (lists, dicts, sets, comprehensions); OOP basics | Understand, Apply |
| 3 | NumPy: arrays, vectorization, broadcasting, linear algebra ops | Apply |
| 4 | pandas: Series/DataFrames, cleaning, merging, exploratory data analysis | Apply |
| 5 | Problem solving as search: state space, BFS/DFS | Understand, Apply |
| 6 | Informed search: greedy, A*, heuristics | Apply, Analyze |
| 7 | Constraint Satisfaction Problems & local search (hill climbing, simulated annealing) | Apply, Analyze |
| 8 | Probability & uncertainty for AI (Bayes' rule, naive Bayes) — Midterm review | Understand, Apply |
| 9 | **Midterm Exam** + Intro to Machine Learning: supervised vs. unsupervised, workflow | Remember–Apply |
| 10 | Regression (linear, logistic) with scikit-learn | Apply, Analyze |
| 11 | Classification (k-NN, decision trees, SVM) and model evaluation metrics | Apply, Analyze, Evaluate |
| 12 | Unsupervised learning: k-means clustering, PCA | Apply, Analyze |
| 13 | Model evaluation, overfitting, cross-validation, hyperparameter tuning | Analyze, Evaluate |
| 14 | Neural networks I: perceptron, forward pass, activation functions | Understand, Apply |
| 15 | Neural networks II: backpropagation, training with PyTorch/Keras | Apply, Analyze |
| 16 | Capstone mini-project presentations; course review; ethics in AI | Evaluate, Create |
| 17 | Final Exam Week | — |

## 6. Assessment Plan

| Component | Weight | Notes |
|---|---|---|
| Lab Work (weekly) | 20% | Graded notebooks/scripts, submitted weekly |
| Assignments (4) | 20% | Problem sets tied to Weeks 2, 6, 10, 13 |
| Quizzes (6, best 5 counted) | 10% | Short, in-class/online, 15 min each |
| Midterm Exam | 15% | Week 9, covers Weeks 1–8 |
| Capstone Mini-Project | 20% | Proposal (Wk 10) + implementation + presentation (Wk 16) |
| Final Exam | 15% | Comprehensive, emphasis on Weeks 9–16 |

## 7. Grading Policy

Standard letter grading per institutional policy (e.g., A ≥ 85, B ≥ 70, C ≥ 55, D ≥ 40, F < 40;
adjust to institution). Late submissions: −10% per day up to 3 days, then not accepted unless
documented emergency.

## 8. Tools & Software

- Python 3.10+, pip/conda
- Jupyter Notebook / Google Colab
- NumPy, pandas, Matplotlib/Seaborn
- scikit-learn
- PyTorch or TensorFlow/Keras (Weeks 14–16)
- Git/GitHub for lab and project submission

## 9. Reference Textbooks

- Russell, S. & Norvig, P. — *Artificial Intelligence: A Modern Approach* (classical AI chapters).
- VanderPlas, J. — *Python Data Science Handbook* (NumPy/pandas/scikit-learn chapters).
- Géron, A. — *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow*.
- Official Python, NumPy, pandas, and scikit-learn documentation.

## 10. Academic Integrity

Labs and assignments are individual unless stated otherwise. The capstone project may be done in
pairs with clearly attributed contributions. Code plagiarism (including uncredited AI-generated
code submitted as original work) is handled per institutional academic integrity policy.
