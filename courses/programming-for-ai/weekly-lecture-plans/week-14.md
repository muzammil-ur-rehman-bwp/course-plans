# Week 14 Lecture Plan — Programming for AI
## Topic: Neural Networks I — Perceptron & Forward Pass

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain the structure of a perceptron and a feedforward network. (*Understand*)
2. Apply activation functions (sigmoid, ReLU, softmax) and compute a forward pass by hand and in code. (*Apply*)
3. Analyze how loss functions quantify prediction error. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:15 | Biological inspiration (brief) | Neuron analogy, historical note |
| 0:15–0:45 | The perceptron | Weighted sum + activation, single-layer limitations (XOR problem) |
| 0:45–0:55 | Break | — |
| 0:55–1:30 | Activation functions | Sigmoid, ReLU, softmax — behavior and use cases |
| 1:30–2:00 | Forward propagation | Implement a 2-layer forward pass in NumPy "from scratch" |

### Materials/Equipment
- Live-coding environment, NumPy
- Diagram handout: feedforward network architecture

### Formative Check (in-class)
Exercise: compute a 2-layer forward pass by hand for a tiny example, then verify with NumPy code.

### Link to Lab/Assessment
Lab 14: Implement perceptron + 2-layer forward pass in NumPy.
