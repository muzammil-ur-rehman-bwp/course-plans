# Week 12 Lecture Plan — Programming for AI
## Topic: Unsupervised Learning — Clustering & Dimensionality Reduction

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain the k-means algorithm and how to choose k. (*Understand*)
2. Apply k-means clustering and PCA using scikit-learn. (*Apply*)
3. Analyze clustering results and reduced-dimension visualizations for structure/validity. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | k-means | Algorithm (assign/update loop), live demo |
| 0:30–0:55 | Choosing k | Elbow method, live demo |
| 0:55–1:05 | Break | — |
| 1:05–1:35 | PCA | Variance/components intuition, live demo on a high-dimensional dataset |
| 1:35–2:00 | Putting it together | Cluster a dataset, visualize via PCA-reduced 2D scatter plot |

### Materials/Equipment
- Live-coding environment, scikit-learn, Matplotlib
- Dataset with ≥4 numeric features (e.g., Iris without labels, or customer data)

### Formative Check (in-class)
Exercise: run k-means with different k values and justify a choice using the elbow plot.

### Link to Lab/Assessment
Lab 12: Clustering + PCA visualization lab.
