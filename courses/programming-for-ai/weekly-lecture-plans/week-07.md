# Week 7 Lecture Plan — Programming for AI
## Topic: Constraint Satisfaction Problems & Local Search

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain CSP formulation (variables, domains, constraints). (*Understand*)
2. Apply backtracking search with forward checking to solve a CSP. (*Apply*)
3. Apply local search methods (hill climbing, simulated annealing) to an optimization problem. (*Apply*)
4. Analyze why local search can get stuck in local optima and how simulated annealing addresses it. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | CSP formulation | Variables/domains/constraints, examples (map coloring, N-Queens) |
| 0:25–0:55 | Backtracking + forward checking | Live-coded N-Queens solver |
| 0:55–1:05 | Break | — |
| 1:05–1:30 | Hill climbing | Algorithm, local optima problem, live demo |
| 1:30–2:00 | Simulated annealing | Algorithm, temperature schedule, live demo on same problem |

### Materials/Equipment
- Live-coding environment
- Starter notebook: N-Queens / Sudoku CSP skeleton

### Formative Check (in-class)
Exercise: identify the variables/domains/constraints for a Sudoku puzzle as a CSP.

### Link to Lab/Assessment
Lab 7: Solve N-Queens via backtracking CSP and via simulated annealing; compare approaches.
