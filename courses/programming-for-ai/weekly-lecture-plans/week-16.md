# Week 16 Lecture Plan — Programming for AI
## Topic: Capstone Presentations, Course Review, AI Ethics

**Duration:** 2 hours lecture + 3 hour lab (presentations may span both)

### Learning Objectives (Bloom's Level)
1. Evaluate peers' capstone projects against stated goals and course techniques used. (*Evaluate*)
2. Create and deliver an original AI mini-project with a clear problem framing and results. (*Create*)
3. Explain key ethical considerations in AI (bias, fairness, privacy, responsible use). (*Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:30 | Capstone presentations | 5–7 min per student/team + Q&A |
| 1:30–1:50 | Course review | Recap: search → CSP → probability → ML → neural nets |
| 1:50–2:00 | AI ethics discussion | Bias/fairness, data privacy, responsible use of AI-generated code |

### Materials/Equipment
- Projector/screen for student presentations
- Rubric for capstone grading (see `assignments/capstone-rubric.md`)

### Formative Check (in-class)
Peer feedback forms during presentations (one strength + one question per project).

### Link to Lab/Assessment
**Capstone project final submission + presentation due.** Final Exam in Week 17.
