# Week 2 Lecture Plan — Programming for AI
## Topic: Data Structures & OOP in Python

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall Python's built-in data structures and their key operations. (*Remember*)
2. Explain tradeoffs between lists, tuples, dicts, and sets for different use cases. (*Understand*)
3. Use comprehensions to transform data concisely. (*Apply*)
4. Implement a simple class with attributes and methods for reuse in later AI algorithms. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | Lists, tuples, sets, dicts | Live-coded comparisons, complexity notes |
| 0:30–0:55 | Comprehensions | List/dict comprehensions, live refactor of loop code |
| 0:55–1:05 | Break | — |
| 1:05–1:40 | OOP basics | `class`, `__init__`, methods, simple inheritance |
| 1:40–2:00 | Worked example | Build a small `Graph` class (nodes/edges) for later search labs |

### Materials/Equipment

- Starter notebook: "Data Structures Playground"
