# Week 4 Lecture Plan — Programming for AI
## Topic: pandas & Exploratory Data Analysis

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain the Series/DataFrame data model. (*Understand*)
2. Apply pandas operations to load, clean, filter, group, and merge data. (*Apply*)
3. Analyze a dataset through exploratory data analysis (EDA) to surface patterns/issues. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | Series & DataFrame | Core data model, reading CSV/JSON |
| 0:20–0:50 | Indexing & filtering | `loc`/`iloc`, boolean masks, live demo |
| 0:50–1:00 | Break | — |
| 1:00–1:30 | Grouping, aggregation, merging | `groupby`, `merge`/`join`, missing data handling |
| 1:30–2:00 | EDA walkthrough | Full EDA notebook on a public dataset with Matplotlib plots |

### Materials/Equipment
- Live-coding environment
- Public dataset (e.g., Titanic or Iris CSV)

### Formative Check (in-class)
Exercise: find and handle missing values in the demo dataset; produce one summary plot.

### Link to Lab/Assessment
Lab 4: EDA notebook on a new dataset. **Assignment 1** assigned this week (Python + NumPy/pandas
problem set, covers Weeks 1–4), due start of Week 6.
