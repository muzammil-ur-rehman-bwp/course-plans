# Week 8 Lecture Plan — Programming for AI
## Topic: Probability & Uncertainty for AI; Midterm Review

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall basic probability rules and Bayes' rule. (*Remember*)
2. Explain how Bayes' rule underlies the Naive Bayes classifier. (*Understand*)
3. Apply a simple Naive Bayes classifier to a text classification task. (*Apply*)
4. Evaluate one's own readiness for the midterm by solving practice problems across Weeks 1–7. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Probability basics | Joint/conditional probability, independence, Bayes' rule derivation |
| 0:25–0:55 | Naive Bayes | Conditional-independence assumption, worked example (spam classification) |
| 0:55–1:05 | Break | — |
| 1:05–2:00 | Midterm review | Practice problems spanning Python/NumPy/pandas, search, CSP, probability; open Q&A |

### Materials/Equipment
- Live-coding environment
- Midterm review problem set handout

### Formative Check (in-class)
In-class practice midterm questions (ungraded), peer discussion of answers.

### Link to Lab/Assessment
Lab 8: Implement a Naive Bayes text classifier from scratch (no scikit-learn yet). **Assignment 2**
due at the start of this week.
