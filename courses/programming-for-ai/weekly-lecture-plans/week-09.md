# Week 9 Lecture Plan — Programming for AI
## Topic: Midterm Exam + Intro to Machine Learning

**Duration:** 2 hours lecture + 3 hour lab (exam occupies part of lecture time)

### Learning Objectives (Bloom's Level)
1. Demonstrate recall and application of Weeks 1–8 material under exam conditions. (*Remember, Apply*)
2. Explain the supervised/unsupervised/reinforcement learning taxonomy. (*Understand*)
3. Explain the standard ML workflow (data → features → train → evaluate → deploy). (*Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:00 | **Midterm Exam** | Closed-book/open-notes per instructor policy, covers Weeks 1–8 |
| 1:00–1:10 | Break | — |
| 1:10–1:35 | ML taxonomy | Supervised vs. unsupervised vs. reinforcement, examples of each |
| 1:35–2:00 | The ML workflow | Data → features → train/test split → model → evaluate; scikit-learn intro |

### Materials/Equipment
- Midterm exam paper/online quiz
- Slides: "The Machine Learning Workflow"

### Formative Check (in-class)
Post-exam discussion: classify 5 example problems as supervised/unsupervised/reinforcement.

### Link to Lab/Assessment
