# Week 3 Lecture Plan — Programming for AI
## Topic: NumPy for Numerical Computing

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain what vectorization is and why it matters for AI workloads. (*Understand*)
2. Apply NumPy array creation, indexing, slicing, and broadcasting. (*Apply*)
3. Apply basic linear algebra operations (`dot`, `matmul`, `linalg.inv`) relevant to AI math. (*Apply*)
4. Analyze performance differences between pure-Python loops and vectorized NumPy code. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | Why NumPy | Motivation: speed, memory layout, AI/ML dependence on arrays |
| 0:20–0:50 | Array basics | Creation, shape/dtype, indexing/slicing, live demo |
| 0:50–1:00 | Break | — |
| 1:00–1:30 | Broadcasting & vectorization | Live demo: loop vs. vectorized, timing comparison |
| 1:30–2:00 | Linear algebra ops | `dot`, `matmul`, `linalg`, random generation |

### Materials/Equipment
- Live-coding environment
- Starter notebook: "NumPy Essentials"

### Formative Check (in-class)
Exercise: vectorize a provided nested-loop distance calculation and time both versions.

### Link to Lab/Assessment
Lab 3: NumPy exercises (array manipulation, vectorization, linear algebra).
