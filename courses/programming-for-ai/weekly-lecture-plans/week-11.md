# Week 11 Lecture Plan — Programming for AI
## Topic: Classification & Model Evaluation Metrics

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Apply k-NN, Decision Tree, and SVM classifiers using scikit-learn. (*Apply*)
2. Analyze classifier performance using confusion matrices and metrics (precision, recall, F1). (*Analyze*)
3. Evaluate which classifier is most appropriate for a given dataset/task. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | k-NN | Algorithm, distance metrics, live demo |
| 0:30–0:55 | Decision Trees & SVM (brief) | Core ideas, live demo |
| 0:55–1:05 | Break | — |
| 1:05–1:35 | Evaluation metrics | Accuracy, precision, recall, F1, confusion matrix |
| 1:35–2:00 | ROC/AUC & model comparison | Plotting ROC curves; comparing the three classifiers on one dataset |

### Materials/Equipment
- Live-coding environment, scikit-learn
- Classification dataset (e.g., Iris or a tabular dataset with 2+ classes)

### Formative Check (in-class)
Exercise: compute precision/recall by hand from a given confusion matrix, then verify with code.

### Link to Lab/Assessment
Lab 11: Train and compare 3 classifiers; produce a classification report for each. **Assignment 3**
assigned this week (classification + evaluation), due start of Week 13.
