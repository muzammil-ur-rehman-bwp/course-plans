# Week 10 Lecture Plan — Programming for AI
## Topic: Regression with scikit-learn

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain linear regression's cost function and the intuition behind gradient descent. (*Understand*)
2. Apply `LinearRegression` and `LogisticRegression` from scikit-learn to real data. (*Apply*)
3. Analyze model fit by plotting predictions vs. actuals and interpreting coefficients. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Linear regression theory | Cost function (MSE), gradient descent intuition |
| 0:25–0:50 | Linear regression in scikit-learn | Live demo: fit, predict, plot |
| 0:50–1:00 | Break | — |
| 1:00–1:30 | Logistic regression | Sigmoid function, decision boundary, binary classification |
| 1:30–2:00 | Feature scaling & interpretation | `StandardScaler`, interpreting coefficients |

### Materials/Equipment
- Live-coding environment, scikit-learn
- Dataset: e.g., housing prices (regression), simple binary dataset (classification)

### Formative Check (in-class)
Exercise: fit a logistic regression model and report accuracy on a held-out test set.

### Link to Lab/Assessment
Lab 10: Regression lab (linear + logistic). **Capstone project proposal due this week.**
