# Week 1 Lecture Plan — Programming for AI
## Topic: Python Essentials & the AI Tooling Landscape

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall Python syntax: variables, types, operators, control flow. (*Remember*)
2. Explain the role of each major library in the Python AI/ML stack (NumPy, pandas,
   scikit-learn, PyTorch/TensorFlow). (*Understand*)
3. Write and run simple scripts/notebooks implementing conditionals, loops, and functions. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Course intro | Syllabus walkthrough, grading, capstone preview |
| 0:10–0:35 | Python syntax recap | Live-coded demo: variables, types, operators |
| 0:35–1:00 | Control flow & functions | Live-coded demo: if/for/while, function definitions |
| 1:00–1:40 | AI/ML tooling landscape | Slide walkthrough: where NumPy/pandas/scikit-learn/PyTorch fit in a typical AI pipeline |
| 1:40–2:00 | Environment setup | Jupyter/Colab demo; venv/conda; `pip install` |

### Materials/Equipment
- Slides: "AI/ML Python Ecosystem Map"
- Live-coding environment (Jupyter)
- Handout: Python quick-reference cheat sheet

### Formative Check (in-class)
Quick poll/exercise: write a function that returns the max of a list without using `max()`.
