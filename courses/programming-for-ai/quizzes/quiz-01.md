# Quiz 1 — Python Essentials & Data Structures (Week 2)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What is the output of `print([x**2 for x in range(5) if x % 2 == 0])`? (2 pts)
2. Explain the difference between a `list` and a `tuple` in Python. Give one scenario where you
   would prefer each. (3 pts)
3. Write a one-line dict comprehension that maps each string in `["a", "bb", "ccc"]` to its
   length. (2 pts)
4. What does `self` refer to inside a class method? (1 pt)
5. Fix the bug in the following code:
   ```python
   def add_to_list(item, target=[]):
       target.append(item)
       return target
   ```
   (Hint: think about what happens on repeated calls with no `target` argument.) (2 pts)
