# Presentation: Module 1 — Foundations, Agents & Search (Weeks 1–4)

1. **Title slide** — Introduction to AI: Module 1, Foundations, Agents & Search
2. **What is AI?** — the 2x2 views-of-AI table (thought/behavior x human/rational)
3. **A short history** — timeline slide: Dartmouth 1956 → expert systems → Deep Blue → AlphaGo
4. **The Turing Test** — setup diagram + one critique (Chinese Room)
5. **PEAS framework** — worked PEAS table for an automated taxi
6. **Agent types** — simple reflex → model-based → goal-based → utility-based ladder diagram
7. **Environment properties** — the six-property table with 3 worked examples
8. **Search problem formulation** — states/actions/transition model/goal test/cost diagram over

9. **BFS vs. DFS** — side-by-side traversal diagram, complexity table
10. **Heuristics & A\*** — Manhattan distance example on a grid; `f = g + h` diagram
11. **Local search** — hill-climbing landscape diagram showing local optima; simulated-annealing
    temperature-schedule diagram
12. **Module 1 recap** — key skills checklist
13. **Looking ahead** — "Next: adversarial search — when another agent is working against you"

**Speaker notes:** this module sets up the vocabulary (PEAS, agent types, environment
properties) that every later module quietly relies on — resist the urge to rush it to "get to
the algorithms."
