# Quiz 3 — Propositional Logic (Week 6)

**Duration:** 15 minutes | **Format:** 5 short-answer questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. Write the truth table row for `P = True, Q = False` for the sentence `P → Q`. (1 pt)
2. What is the difference between a satisfiable sentence and a valid (tautological) sentence?
   (2 pts)
3. State De Morgan's law for `¬(P ∨ Q)`. (2 pts)
4. Is `P ∧ ¬P` satisfiable, valid, or unsatisfiable? (1 pt)
5. Rewrite `P → Q` using only `¬` and `∨` (implication elimination). (2 pts)
