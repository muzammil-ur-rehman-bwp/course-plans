# Lab Assignment 9 — Classical Planning: A Toy STRIPS Planner (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab09.ipynb` with working solutions to Tasks A–D from `lab-manuals/lab-09.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (3+ correctly specified STRIPS action schemas) | 3 |
| Task B correct (forward search finds the 1-step plan) | 2 |
| Task C correct (forward search finds a correct 2+ step plan) | 3 |
| Task D correct (states-expanded analysis, relates to Lab 3 search) | 2 |
| **Total** | **10** |

## Notes
A plan is only correct if applying each action in sequence from the initial state actually
reaches a state containing the goal facts — a plan that merely "runs without error" is not
sufficient for credit.
