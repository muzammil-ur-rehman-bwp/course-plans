# Week 1 Lecture Plan — Introduction to AI
## Topic: What Is AI? History, the Turing Test, and the PEAS Framework

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the four historical views of AI (thinking/acting humanly, thinking/acting rationally) and 3–4 key historical milestones. (*Remember*)
2. Explain the Turing Test and one standard critique of it as a definition of intelligence. (*Understand*)
3. Apply the PEAS framework to describe a given task environment. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:15 | Course overview | Syllabus walkthrough, assessment plan, how this course differs from an applied-ML course |
| 0:15–0:45 | What is AI? | Four views of AI; definitions compared with examples |
| 0:45–1:10 | History & milestones | Dartmouth 1956 → expert systems → Deep Blue → AlphaGo → the deep learning era (timeline) |
| 1:10–1:20 | Break | — |
| 1:20–1:40 | The Turing Test | Setup, what it tests for, common critiques (Chinese Room, behaviorism) |
| 1:40–2:00 | PEAS framework | Performance measure, Environment, Actuators, Sensors; worked PEAS examples (automated taxi, vacuum robot) |

### Materials/Equipment
- Slides: AI timeline, PEAS worked examples
- Python/Jupyter environment check (for Lab 1)

### Formative Check (in-class)
Exercise: in pairs, write a PEAS description for a chess-playing program; compare answers across
the room and discuss disagreements.

### Link to Lab/Assessment
Lab 1: Set up the Python/Jupyter lab environment; write PEAS descriptions for three task
environments; implement a trivial table-driven agent skeleton.
