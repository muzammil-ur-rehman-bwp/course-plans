# Week 2 Lecture Plan — Introduction to AI
## Topic: Intelligent Agents

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Distinguish the agent function from the agent program. (*Understand*)
2. Classify an agent as simple reflex, model-based reflex, goal-based, or utility-based. (*Analyze*)
3. Classify an environment by its properties (observability, determinism, episodicity, etc.) and explain the implications for agent design. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | Agents & environments | Perception-action loop diagram; agent function vs. agent program |
| 0:20–0:50 | Agent types | Simple reflex → model-based reflex → goal-based → utility-based, with examples at each level |
| 0:50–1:00 | Break | — |
| 1:00–1:30 | Environment properties | Observable, deterministic, episodic, static, discrete, single/multi-agent — defined and illustrated |
| 1:30–2:00 | Worked classification | Classify 5 example environments (chess, taxi driving, crossword, poker, vacuum world) as a class exercise |

### Materials/Equipment
- Slides: agent architecture diagrams, environment-property table
- Starter code: vacuum-world skeleton (grid, dirt locations, agent position)

### Formative Check (in-class)
Exercise: for each of the 5 example environments, fill in the environment-property table live
and justify each entry.

### Link to Lab/Assessment
Lab 2: Implement a simple reflex agent and a model-based reflex agent for the vacuum-cleaner
world.
