# Week 14 Summary — Natural Language Processing Overview

**Key takeaways:**
- Natural language is hard for AI because it is ambiguous, context-dependent, and relies on
  world knowledge — challenges beyond what formal logic (Weeks 6–8) alone can resolve.
- Tokenization splits text into discrete units; bag-of-words represents a document as a word-
  count vector, discarding word order entirely.
- Bag-of-words is simple and useful for toy classification but loses information (e.g.,
  negation, word order) that more advanced representations (n-grams, modern language models)
  attempt to capture.

**You should now be able to:** implement a simple tokenizer and bag-of-words vectorizer; state
one concrete limitation of the bag-of-words representation with an example.
