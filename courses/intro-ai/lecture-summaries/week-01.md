# Week 1 Summary — Introduction to AI

**Key takeaways:**
- AI can be viewed along two axes: thought vs. behavior, human-centered vs. rationality-
  centered; this course adopts the "acting rationally" view.
- Key historical milestones (Dartmouth 1956, expert systems, Deep Blue, AlphaGo, the deep
  learning era) show two intertwined threads: classical/symbolic AI and statistical/learning AI.
- The Turing Test operationalizes "acting humanly" but has well-known critiques (Chinese Room,
  rewarding mimicry over understanding).
- The PEAS framework (Performance measure, Environment, Actuators, Sensors) is the first,
  essential step in designing any agent.

**You should now be able to:** state the four views of AI; name 3–4 historical milestones;
explain the Turing Test and one critique; write a PEAS description for a given task environment.

**Next week:** intelligent agents — agent architectures (simple reflex, model-based, goal-based,
utility-based) and the environment properties that determine which architecture fits.
