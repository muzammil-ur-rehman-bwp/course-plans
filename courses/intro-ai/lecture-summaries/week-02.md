# Week 2 Summary — Intelligent Agents

**Key takeaways:**
- The agent function maps percept histories to actions; the agent program is its concrete
  implementation.
- Agent types form a spectrum of increasing sophistication: simple reflex, model-based reflex,
  goal-based, utility-based (optionally paired with a learning element).
- Environment properties (observable, deterministic, episodic, static, discrete,
  single/multi-agent) determine how sophisticated an agent's architecture needs to be.
- Harder environments (partially observable, stochastic, sequential, dynamic, continuous,
  multi-agent) generally require more internal structure than simple reflex agents provide.

**You should now be able to:** classify an agent by type; classify an environment by its six
properties; implement a simple reflex agent and a model-based reflex agent in Python.
