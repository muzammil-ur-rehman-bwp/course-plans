# Week 12 Summary — Introduction to Machine Learning (Survey)

**Key takeaways:**
- Learning agents improve their performance element from experience rather than relying entirely
  on hand-specified rules.
- Supervised learning maps inputs to known labels (regression/classification); unsupervised
  learning finds structure without labels (e.g., clustering).
- A decision tree is built by recursively splitting on the attribute with the highest
  information gain (entropy reduction) — small enough to trace fully by hand on a toy dataset.
- A held-out test set is needed to estimate generalization, not just training performance.

**You should now be able to:** compute entropy and information gain by hand; build a one-level
decision tree on a toy dataset; explain why training accuracy alone is a misleading metric.
