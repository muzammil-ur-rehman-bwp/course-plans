# Week 6 Summary — Knowledge Representation & Propositional Logic

**Key takeaways:**
- Propositional logic sentences are built from propositional symbols and connectives
  (¬, ∧, ∨, →, ↔); a model assigns truth values to every symbol.
- A sentence can be satisfiable, valid (a tautology), or unsatisfiable (a contradiction), each
  checkable via a full truth table.
- Logical equivalence (two sentences with identical truth tables) underlies rewriting rules like
  implication elimination and De Morgan's laws.

**You should now be able to:** evaluate a propositional sentence under a model; build a truth
table; determine satisfiability/validity; check logical equivalence between two sentences.
