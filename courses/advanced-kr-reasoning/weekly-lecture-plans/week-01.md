# Week 1 Lecture Plan — Advanced Knowledge Representation and Reasoning (Post Graduate)
## Topic: Postgraduate Overview

**Duration:** 2 hours lecture + 3 hour research seminar/lab

### Learning Objectives (Bloom's Level)
1. Restate, from memory, the core formalism/result for each assumed graduate KR&R topic.
   (*Remember*)
2. Map the landscape of advanced-KR research this course covers onto the 16-week schedule.
   (*Understand*)
3. Sketch a one-paragraph tentative personal research direction for the capstone. (*Understand,
   Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | Course logistics | Syllabus walkthrough, assessment plan, capstone timeline |
| 0:20–1:00 | Graduate-foundations rapid review | One-slide-per-topic recall: modal/temporal logic, ALC tableau, ASP, AGM, Dung AF, MLNs, RDF/TransE, epistemic logic, ontology engineering, explainability |
| 1:00–1:30 | The advanced-KR landscape | Four pillars of this course mapped to weeks 2–16 |
| 1:30–1:50 | Scoping a research proposal (preview) | One-slide sketch: problem statement / survey / approach / feasibility — full treatment Week 13 |
| 1:50–2:00 | Synthesis | Course-scope boundary check against sibling courses |

### Materials/Equipment
- Slides: "Advanced KR&R: Postgraduate Overview"
- Whiteboard for the foundations-recall diagnostic
- Jupyter environment check

### Formative Check (in-class)
For three randomly assigned graduate-course topics, each student states the core formalism/result
in one sentence and names one sibling course (graduate KR&R, or a postgraduate sibling) this
course is explicitly not about, for a given advanced-KR research question.

### Link to Lab/Assessment
Lab 1: environment setup + foundations-recall diagnostic + capstone-direction sketch (see
`lab-manuals/lab-01.md`).
