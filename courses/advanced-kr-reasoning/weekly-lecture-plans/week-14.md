# Week 14 Lecture Plan — Advanced Knowledge Representation and Reasoning (Post Graduate)
## Topic: Current Open Problems Survey

**Duration:** 2 hours lecture + 3 hour research seminar/lab

### Learning Objectives (Bloom's Level)
1. State the precise technical obstacle behind 2–3 currently open KR research problems.
   (*Understand, Evaluate*)
2. Name one partial approach and its limitation for each surveyed problem. (*Analyze, Evaluate*)
3. Connect a surveyed open problem to one's own capstone scoping. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Framing | This is a fast-moving survey, not settled textbook material |
| 0:10–0:40 | Open problem 1 | Scaling expressive-DL reasoning/justification without losing explainability |
| 0:40–1:10 | Open problem 2 | Integrating probabilistic and paraconsistent/many-valued semantics |
| 1:10–1:40 | Open problem 3 | Guaranteeing neuro-symbolic systems respect symbolic constraints |
| 1:40–2:00 | Capstone scoping check | Is your problem statement appropriately scoped against these? |

### Materials/Equipment
- Slides: "Current Open Problems in Advanced KR Research" (refreshed each offering)
- Current KR/IJCAI/AAAI papers selected by the instructor

### Formative Check (in-class)
For one surveyed open problem, state its specific technical obstacle precisely and name one
partial approach's known limitation.

### Link to Lab/Assessment
Lab 14: written open-problem connection exercise, linking one surveyed problem to the student's
capstone direction (see `lab-manuals/lab-14.md`).
