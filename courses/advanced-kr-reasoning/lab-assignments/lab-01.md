# Lab Assignment 1 — Environment Setup & Foundations Diagnostic (Graded)

**Weight:** part of the weekly Lab Work component (10% of course grade, averaged across all labs).

## Deliverable
Submit `lab01.ipynb` containing complete, working responses to Tasks A–D from
`lab-manuals/lab-01.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (environment verified, both snippets run) | 2 |
| Task B complete (10 topics addressed, each a correct one-sentence statement or honestly flagged) | 3 |
| Task C correct (scope-mapping for all 3 questions, correct sibling course named) | 3 |
| Task D complete (a genuine, pillar-connected capstone-direction paragraph) | 2 |
| **Total** | **10** |

## Notes
- Task B is graded on accuracy and honesty, not on getting every topic right — a correctly
  flagged gap earns full credit for that item; an incorrect but confidently-stated answer does
  not.
- Task D is not evaluated for how "good" the idea is — only that it is a genuine, specific,
  pillar-connected sketch rather than a placeholder sentence.
