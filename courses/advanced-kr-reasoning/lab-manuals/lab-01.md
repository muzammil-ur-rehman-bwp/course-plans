# Lab Manual 1 — Environment Setup & Foundations Diagnostic

**Duration:** 3 hours | **Prerequisite:** Week 1 lecture

## Objectives
Verify the Python/Jupyter environment; complete a graduate-foundations recall diagnostic; sketch
a tentative capstone research direction.

## Setup
1. Install/verify Python 3.10+, Jupyter Notebook or Colab access, NumPy, and PyTorch (needed from
   Week 7 onward — verify now to avoid a mid-semester blocker).
2. Create `lab01.ipynb`.

## Procedure
1. **Task A — Environment check:** in a markdown cell, record your Python, NumPy, and PyTorch
   versions; run a trivial NumPy and PyTorch snippet (e.g., a small array/tensor sum) to confirm
   both import and run correctly.
2. **Task B — Foundations diagnostic:** for each of the 10 assumed graduate-course topics listed
   in `weekly-lecture-content/week-01.md` §1, write one correct sentence (from memory, no notes)
   stating its core formalism or result. Self-score against the lecture content afterward and
   flag any topic you could not state correctly for independent review this week.
3. **Task C — Scope-mapping exercise:** for three instructor-provided advanced-KR research
   questions, state which of this course's 16 weeks it maps onto and name one sibling course
   (graduate KR&R, or a postgraduate sibling) it is explicitly not about.
4. **Task D — Capstone-direction sketch:** write a one-paragraph tentative research direction of
   personal interest, connected to one of this course's four pillars (not a commitment — revisited
   in Week 13).

## Expected Output
A notebook with four clearly labeled cells/sections (A–D) with working environment checks and
complete written responses.

## Submission
Export/submit `lab01.ipynb` via the course submission system by the end of the lab session.
