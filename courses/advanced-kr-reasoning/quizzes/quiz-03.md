# Quiz 3 — ASPIC+ & Probabilistic Logic Programming (Weeks 5–6)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of
Quizzes (10%, best 5 of 6 counted)

1. State the difference between a rebutting attack and an undercutting attack in ASPIC+, in
   terms of what each one targets. (2 pts)
2. True or false, with one sentence of justification: a strict rule's conclusion can be
   legitimately rebutted in ASPIC+. (2 pts)
3. Define a "total choice" in the distribution semantics, and state how its probability is
   computed. (2 pts)
4. For a program with one probabilistic fact `0.4 :: f` and a rule `q :- f.`, compute `P(q)` by
   total-choice enumeration. (2 pts)
5. A colleague claims: "The distribution semantics and Markov Logic Networks are really the same
   formalism with different notation." Identify one genuine structural difference between them.
   (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
