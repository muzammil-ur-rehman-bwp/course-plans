# Quiz 1 — Higher-Order Logic and Type Theory (Week 3)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of
Quizzes (10%, best 5 of 6 counted)

1. State one property expressible in second-order logic that plain first-order logic cannot
   express, and explain why FOL cannot express it. (2 pts)
2. Given base types `e` and `t`, write the type of a term `λx:e. λy:e. R x y` where
   `R : e → e → t`. (2 pts)
3. State the β-reduction rule precisely: `(λx:σ. M) N → ?`. (2 pts)
4. True or false, with one sentence of justification: a relation such as `R` in Question 2 can be
   passed as an argument to another function in the simply-typed lambda calculus. (2 pts)
5. A colleague claims: "Second-order logic is just first-order logic with more variables."
   Identify what is wrong with this claim. (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
