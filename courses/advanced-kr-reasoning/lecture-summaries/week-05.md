# Week 5 Summary — Structured Argumentation: ASPIC+

**Key takeaways:**
- ASPIC+ builds arguments as trees from strict rules, defeasible rules, and premises, in contrast
  to Dung's opaque argument nodes.
- A rebutting attack targets a conclusion; an undercutting attack targets a defeasible rule's
  applicability; undermining targets an ordinary premise directly.
- A preference ordering turns attacks into defeats, producing a Dung framework that the graduate
  course's grounded/preferred extensions then apply to directly.

**You should now be able to:** construct ASPIC+ arguments from rules/premises; correctly classify
an attack as rebutting, undercutting, or undermining.
