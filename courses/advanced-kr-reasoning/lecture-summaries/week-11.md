# Week 11 Summary — Explanation and Justification Research

**Key takeaways:**
- A justification for an entailment is a minimal entailing axiom subset; entailments can have
  several distinct justifications, each an independently sufficient reason.
- Black-box justification-finding tests candidate subsets against an unmodified reasoner
  (simple, worst-case exponential); glass-box methods instrument the reasoner's internal search
  (potentially faster, reasoner-specific).
- "A proof tree" and "the full justification set" are different explanation notions once multiple
  independent derivations exist — which is appropriate depends on the use case.

**You should now be able to:** construct and verify minimal justifications by hand; implement a
black-box justification finder; argue which explanation notion fits a given scenario.
