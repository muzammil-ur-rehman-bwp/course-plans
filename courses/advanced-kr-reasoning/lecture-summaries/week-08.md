# Week 8 Summary — Neuro-Symbolic Integration II; Midterm Review

**Key takeaways:**
- Neural theorem proving replaces exact unification with a soft, embedding-similarity score,
  gaining learned generalization but losing exactness/interpretability.
- Combining KG embeddings with explicit logical constraints lets rules filter/veto confidently-
  wrong embedding-proposed candidates, trading off rules' exactness against embeddings' noise
  tolerance — neither solved, both active research.
- Midterm (Week 9) covers Weeks 1–8: HOL/type theory, many-valued/paraconsistent logics, SROIQ,
  ASPIC+, distribution semantics, differentiable logic, neuro-symbolic integration.

**You should now be able to:** explain what soft unification gains and loses relative to exact
unification; implement a constraint-based filter over embedding-ranked candidates.
