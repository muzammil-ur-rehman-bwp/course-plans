# Week 2 Summary — Higher-Order Logic and Type Theory

**Key takeaways:**
- FOL cannot quantify over predicates/relations themselves (e.g., the single-sentence induction
  principle); second-order and higher-order logic add this quantification.
- The simply-typed lambda calculus (base types, function types σ→τ, abstraction, application,
  β-reduction) gives HOL a standard syntactic foundation, letting a relation be a first-class term.
- Typed representations underlie real systems: Montague-style compositional semantics and typed
  feature structures.

**You should now be able to:** state a property expressible in second-order but not first-order
logic; type-check and β-reduce simply-typed lambda terms by hand and in code.

and reasoning over genuine contradiction without explosion.
