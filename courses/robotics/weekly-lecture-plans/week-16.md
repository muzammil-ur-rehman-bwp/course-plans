# Week 16 Lecture Plan — Robotics
## Topic: Capstone Presentations, Course Review, Ethics & Safety

**Duration:** 2 hours lecture + 3 hour lab (presentations may span both)

### Learning Objectives (Bloom's Level)
1. Evaluate peers' capstone robot behaviors against stated goals and techniques used. (*Evaluate*)
2. Create and demonstrate an original autonomous robot behavior (capstone). (*Create*)
3. Explain key safety and ethical considerations in robotics. (*Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:30 | Capstone presentations + demos | 5–7 min per student/team + Q&A |
| 1:30–1:50 | Course review | Recap: kinematics → ROS 2 → sensing → control → vision → planning → navigation |
| 1:50–2:00 | Ethics & safety discussion | Human-robot interaction safety, autonomy, societal impact, data privacy |

### Materials/Equipment
- Projector/screen + simulator for live demos
- Rubric for capstone grading (see `assignments/capstone-rubric.md`)

### Formative Check (in-class)
Peer feedback forms during presentations (one strength + one question per project).

### Link to Lab/Assessment
**Capstone project final submission + presentation due.** Final Exam in Week 17.
