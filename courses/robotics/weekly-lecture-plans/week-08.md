# Week 8 Lecture Plan — Robotics
## Topic: Sensors I — Encoders, IMU, Odometry; Midterm Review

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Explain how wheel encoders and IMUs provide motion information. (*Understand*)
2. Apply odometry equations to estimate robot pose from encoder data. (*Apply*)
3. Evaluate readiness for the midterm via practice problems spanning Weeks 1–7. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Encoders & odometry | Tick counting, odometry update equations |
| 0:25–0:50 | IMU basics | Accelerometer/gyroscope, what each measures |
| 0:50–1:00 | Break | — |
| 1:00–1:20 | Odometry drift | Why errors accumulate over time, live demo of drift |
| 1:20–2:00 | Midterm review | Practice problems: transforms, FK/IK, ROS 2, dynamics, odometry |

### Materials/Equipment
- Live-coding environment, ROS 2 (`nav_msgs/Odometry`, conceptual)
- Midterm review problem set handout

### Formative Check (in-class)
In-class practice midterm questions (ungraded), peer discussion of answers.

### Link to Lab/Assessment
Lab 8: compute odometry from simulated encoder ticks and visualize accumulated drift.
**Assignment 1 due at the start of this week.**
