# Week 1 Lecture Plan — Robotics
## Topic: Introduction to Robotics

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall major robot types and milestones in robotics history. (*Remember*)
2. Explain the sense-plan-act architecture. (*Understand*)
3. Set up the Python/ROS 2/simulator development environment. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Course intro | Syllabus walkthrough, grading, capstone preview |
| 0:10–0:40 | What is a robot? | History/milestones, taxonomy (manipulators, mobile, aerial, humanoid) |
| 0:40–1:10 | Sense-plan-act architecture | Diagram walkthrough; reactive vs. deliberative control (brief) |
| 1:10–1:40 | Course tooling overview | Python, ROS 2, Gazebo/Webots — how they fit together |
| 1:40–2:00 | Environment setup | Live demo: ROS 2 + simulator installation verification |

### Materials/Equipment
- Slides: "What Is a Robot?"
- Dev environment: Python 3.10+, ROS 2, Gazebo/Webots pre-installed on lab machines

### Formative Check (in-class)
Quick poll: classify 5 example robots (vacuum robot, industrial arm, drone, humanoid, self-
driving car) by taxonomy and primary sensing modality.

### Link to Lab/Assessment
Lab 1: environment verification + first ROS 2 "hello world" node run. No graded assignment this
week.
