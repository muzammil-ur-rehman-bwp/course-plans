# Capstone Project — Grading Rubric

**Due:** Week 16 | **Weight:** 20% of course grade total (includes proposal, implementation, presentation)

| Component | Weight (of 20%) | Criteria |
|---|---|---|
| Proposal | 2% | Clear behavior statement, feasible simulation setup, 3+ integrated techniques, sound evaluation plan |
| Implementation — correctness | 6% | Pipeline runs in simulation; implements the proposed techniques correctly |
| Implementation — evaluation | 5% | Appropriate success metric(s) chosen and measured; results reported honestly (including failures) |
| Report | 3% | Concise written report: behavior, approach/pipeline diagram, results, 1+ limitation/next step |
| Presentation & demo | 4% | Clear 5–7 min talk with a live or recorded simulation demo; answers Q&A accurately |

## Grading Notes
- A project that honestly reports a pipeline that partially worked, with sound analysis of where
  it broke down, can score as well as a project with a fully working demo but weak analysis —
  the evaluation and understanding matter as much as a flawless demo.
- Groups must clearly attribute each member's contribution in the report; grading can differ
  between members if contributions were significantly uneven.
