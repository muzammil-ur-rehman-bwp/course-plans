# Lab Manual 13 — Grid-Based Path Planning (A*)

**Duration:** 3 hours | **Prerequisite:** Week 13 lecture; reuse occupancy grid from Lab 9

## Objectives
Implement A* on an occupancy grid and visualize the planned path.

## Setup
Create `lab13.ipynb`; reuse the occupancy grid building code from Lab 9, or use an
instructor-provided grid directly.

## Procedure
1. **Task A — A\* implementation:** implement `a_star_grid` as shown in lecture.
2. **Task B — Planning:** plan a path between two given points on the provided occupancy grid.
3. **Task C — Heuristic comparison:** re-run with Euclidean distance instead of Manhattan
   distance as the heuristic; compare resulting paths and nodes expanded.
4. **Task D — Visualization:** overlay both planned paths on the grid for visual comparison.

## Expected Output
A notebook with Tasks A–D.

## Submission
Submit `lab13.ipynb` by the end of the lab session.
