# Lab Manual 3 — Forward Kinematics

**Duration:** 3 hours | **Prerequisite:** Week 3 lecture

## Objectives
Implement forward kinematics for a 2-link arm and simulate differential-drive motion.

## Setup
Create `lab03.ipynb`.

## Procedure
1. **Task A — 2-link FK:** implement `forward_kinematics_2link`; verify against 2 hand-computed
   test cases.
2. **Task B — Workspace sweep:** sweep joint angles across their full range and plot all
   resulting end-effector positions (a preview of Week 4's workspace visualization).
3. **Task C — Differential-drive pose update:** implement `update_pose`; simulate a robot
   driving in a straight line (equal wheel velocities) and in a circle (unequal velocities).
4. **Task D — Trajectory plot:** plot both trajectories from Task C on the same axes with a
   legend.

## Expected Output
A notebook with Tasks A–D.

## Submission
Submit `lab03.ipynb` by the end of the lab session.
