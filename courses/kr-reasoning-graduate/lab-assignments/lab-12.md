# Lab Assignment 12 — Muddy Children Simulator (Graded)

**Weight:** part of the weekly Lab Work component (15% of course grade, averaged across all
labs).

## Deliverable
Submit `lab12.ipynb` containing working, correct solutions to Tasks A–D from
`lab-manuals/lab-12.md`.

| Criterion | Points |
|---|---|
| Task A correct (n=3, k=2 trace reproduced, returns round 2) | 2 |
| Task B correct (all 5 (n,k) sweep instances return round = k) | 3 |
| Task C correct (clean child correctly shown not to know at round 2) | 2 |
