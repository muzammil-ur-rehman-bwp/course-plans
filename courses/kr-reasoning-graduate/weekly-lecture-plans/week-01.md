# Week 1 Lecture Plan — Knowledge Representation and Reasoning (Graduate)
## Topic: Graduate KR&R Overview

**Duration:** 2 hours lecture + 3 hour lab/seminar

### Learning Objectives (Bloom's Level)
1. Recall, at a diagnostic level, the undergraduate KR&R foundations this course assumes
   (resolution/unification, rule-based systems, semantic networks/frames, DL/ontology basics,
   CSP/AC-3, non-monotonic basics, STRIPS/HTN, Allen's algebra, variable elimination, MLN/fuzzy
   survey). (*Remember*)
2. Map the advanced KR research areas this course covers onto the broader KR landscape, and
   explain how this course's scope is disjoint from the undergraduate course and from sibling
   graduate courses' SAT/DPLL, game-theoretic multi-agent, and CRF content. (*Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:15 | Course intro | Syllabus walkthrough, grading, research capstone preview |
| 0:15–0:55 | Foundations diagnostic | Rapid-fire recap of each assumed undergraduate topic, one slide/one sentence each, with a show-of-hands confidence check |
| 0:55–1:30 | Advanced-KR research map | Slide walkthrough: this course's 16-week map and where it sits relative to the undergraduate course and sibling graduate courses |
| 1:30–1:50 | Scoping discussion | Worked examples: "is this question in this course's scope?" for several sample KR questions |
| 1:50–2:00 | Q&A | Open floor |

### Materials/Equipment
- Slides: "Advanced KR Research Landscape & Course Scope"
- Handout: syllabus + capstone overview + foundations diagnostic checklist
- Live-coding environment (Jupyter)

### Formative Check (in-class)
Given a short KR research-question prompt, identify which subfield(s) of this course's map it
belongs to, and name one sibling course (undergraduate KR&R, *Artificial Intelligence* Graduate,
*Machine Learning* Graduate) it is explicitly NOT about.

### Link to Lab/Assessment
Lab 1: foundations-diagnostic lab + advanced-KR landscape mapping exercise (see
`lab-manuals/lab-01.md`). No graded assignment this week.
