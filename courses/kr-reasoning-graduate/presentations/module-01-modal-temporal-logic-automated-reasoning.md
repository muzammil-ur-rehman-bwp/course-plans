# Presentation: Module 1 — Modal/Temporal Logic & Automated Reasoning (Weeks 1–5)

**Format:** Slide deck outline for lecture delivery (convert to slides in institution's
template).

1. **Title slide** — Knowledge Representation and Reasoning (Graduate): Module 1, Modal/Temporal
   Logic & Automated Reasoning
2. **Course scope recap** — this course's map vs. the undergraduate KR&R course and the sibling
   *Artificial Intelligence*/*Machine Learning* graduate courses
3. **Kripke semantics** — frames, models, the □/◇ satisfaction clauses, worked evaluation
4. **Correspondence theory** — reflexive→T, +transitive→S4, +symmetric (equivalence)→S5, with
   the epistemic reading
5. **LTL operators** — X/G/F/U defined and evaluated on a trace diagram
6. **CTL, conceptually** — branching computation trees, A/E path quantifiers, why AGφ≠Gφ
7. **The ALC tableau algorithm** — completion rules (⊓/⊔/∃/∀), a worked clash and a worked open
   branch
8. **DL complexity & OWL profiles** — PSPACE-completeness of ALC; EL/QL/RL tradeoffs table
9. **Sequent calculus & FOL tableau** — introduction/elimination rules; extending Week 4's
   tableau to unrestricted FOL
10. **Resolution refinements** — set-of-support and ordering strategies, with a resolvent-count
    comparison
11. **Module 1 recap** — key results checklist (S4/S5 correspondence, ALC PSPACE-completeness,
    SOS completeness)
12. **Looking ahead** — "Next: non-monotonic reasoning via ASP, belief revision, and
    argumentation" teaser slide

**Speaker notes:** this module sets the formal-rigor tone for the whole course — spend real time
on the Kripke-model worked evaluations and the ALC tableau's worked clash, since both are the
first "build a model by hand" moments students see this semester.
