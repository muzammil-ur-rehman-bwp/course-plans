# Week 16 Summary — Capstone Research Presentations; Course Review

**Key takeaways:**
- Capstone presentations are this semester's culmination: a literature review, a reproduced or
  extended experiment, a written paper, and a conference-style talk, all on an advanced KR
  subtopic from this course.
- The course map runs modal/temporal logic → DL tableau/complexity → sequent calculus/FOL
  tableau/resolution refinements → ASP → AGM belief revision → argumentation → MLNs → knowledge
  graphs/embeddings → neuro-symbolic KG reasoning → multi-agent epistemic logic → ontology
  engineering → explainability, each building on an undergraduate foundation without re-deriving
  it.
- Current KR&R research sits at the boundary between symbolic/explainable methods and
  statistical/embedding-based methods, with neuro-symbolic integration as an active, unsettled
  area.

**You should now be able to:** present an original research-style project in conference-talk
format; situate every formalism covered this semester within the overall course map and relative
to the undergraduate foundations it builds on.
