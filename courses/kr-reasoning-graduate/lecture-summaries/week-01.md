# Week 1 Summary — Graduate KR&R Overview

**Key takeaways:**
- This course assumes a full undergraduate KR&R course (propositional/FOL resolution,
  unification, rule systems, semantic networks/frames, DL/ontology basics, CSP/AC-3, default
  logic/circumscription, STRIPS/HTN, Allen's algebra, variable elimination, MLN/fuzzy survey) and
  DPLL/SAT from *Artificial Intelligence* Graduate — none of it is re-taught.
- This course's own territory is modal/temporal logic, DL tableau/complexity, sequent calculus
  and resolution refinements, ASP, AGM belief revision, argumentation, MLNs in depth, knowledge
  graphs/embeddings, multi-agent epistemic logic, ontology engineering, and explainability.
- Scope is deliberately disjoint from sibling courses: no SAT/DPLL re-derivation or game-theoretic
  multi-agent treatment (both *Artificial Intelligence* Graduate), and no CRF/structured-
  prediction angle (*Machine Learning* Graduate).

**You should now be able to:** state, from memory, the one-sentence core idea of each assumed
undergraduate KR topic; map a given advanced-KR research question onto this course's week map and
name a sibling course it is not about.

**Next week:** Modal logic — Kripke possible-worlds semantics, the correspondence between
accessibility-relation properties and the modal systems K/S4/S5, and the epistemic reading of
necessity as knowledge.
