# Week 15 Summary — Research Methods and Project Work Session

**Key takeaways:**
- An efficient first pass through a KR paper goes abstract → results/examples → formal
  definitions → related work → full read.
- A KR-specific critique framework asks: what is claimed, is it actually established, are the
  examples representative, how does it compare to formalisms covered this course, and is the
  logic's semantics precise enough to reproduce.
- KR reproducibility hinges on semantic precision (an unambiguous, fully specified formal
  semantics), distinct from the data/seed/hyperparameter reproducibility concerns of empirical ML
  research.

**You should now be able to:** critique a KR paper excerpt using the structured framework; give
and receive specific, actionable feedback on a capstone work-in-progress.
