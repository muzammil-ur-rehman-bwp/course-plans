# Quiz 3 — Answer Set Programming (Week 6)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of
Quizzes (10%, best 5 of 6 counted)

1. Explain the difference between negation as failure (`not c`) and classical negation in one
   sentence. (2 pts)
2. Describe precisely the two steps used to build the Gelfond–Lifschitz reduct P^M from a
   program P and a candidate atom set M. (2 pts)
3. State the condition for M to be a stable model of P, in terms of the reduct. (2 pts)
4. What is the role of an integrity constraint (`:- body.`) in an ASP program — what does it do
   to a candidate stable model that satisfies its body? (2 pts)
5. A colleague claims: "a logic program with no stable models must contain a syntax error."
   Identify what is wrong with this claim. (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
