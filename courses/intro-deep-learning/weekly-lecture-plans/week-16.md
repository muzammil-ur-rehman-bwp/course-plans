# Week 16 Lecture Plan — Introduction to Deep Learning
## Topic: Capstone Presentations + Course Review

**Duration:** 2 hours lecture + 3 hour lab (both sessions used for presentations)

### Learning Objectives (Bloom's Level)
1. Present and defend an original deep learning project, including design trade-offs. (*Create*,
   *Evaluate*)
2. Evaluate peers' projects via structured Q&A. (*Evaluate*)
3. Recall and synthesize the full course map from Week 1 through Week 15. (*Remember*,
   *Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Logistics | Presentation order, timing rules (5–7 min + Q&A) |
| 0:10–1:30 | Capstone presentations (Part 1) | Student presentations with Q&A |
| 1:30–1:40 | Break | — |
| 1:40–3:00 | Capstone presentations (Part 2) | Remaining student presentations with Q&A |
| 3:00–3:20 | Course map recap | Deep nets in practice → CNNs → sequence models → attention/Transformers → generative models → optimization/practice → ethics |
| 3:20–3:30 | Where this leads next | Advanced architecture courses, graduate-level deep learning, specialization paths |

### Materials/Equipment
- Presentation schedule and timing signal
- Course map diagram (reused from Week 15)

### Formative Check (in-class)
After each presentation, each student submits one written question or observation for the
presenting team — used both as engagement evidence and as feedback for the presenters.

### Link to Lab/Assessment
No lab this week (lab sessions are used for presentations). Deliverable: final capstone submission
and presentation, graded per `assignments/capstone-rubric.md`.
