# Lab Assignment 1 — A Mini-World Triple Store (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `lab01.ipynb` with working solutions to Tasks A–D from `lab-manuals/lab-01.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (`TripleStore.add`/`query` work for all wildcard combinations) | 3 |
| Task B correct (mini-world has ≥12 facts, ≥3 distinct predicates) | 2 |
| Task C correct (4 queries, correct and readable results) | 3 |
| Task D correct (clear desiderata discussion, correctly identifies the weak point) | 2 |
| **Total** | **10** |

## Notes
Task D is graded for the *reasoning*, not for picking the "right" awkward fact — any honest,
well-argued example that correctly names the weak desideratum earns full credit.
