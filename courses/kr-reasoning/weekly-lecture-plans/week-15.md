# Week 15 Lecture Plan — Knowledge Representation and Reasoning
## Topic: Current Trends in Knowledge Representation

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Describe knowledge graphs as the large-scale descendant of semantic networks, and implement a
   triple store with pattern queries. (*Understand, Apply*)
2. Describe neuro-symbolic AI as a conceptual survey of combining symbolic KR with learned
   components. (*Understand*)
3. Evaluate a KR system along the axes of correctness, scalability, and explainability.
   (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | Knowledge graphs | Triple stores and property graphs at scale; real-world examples (conceptual) |
| 0:30–1:00 | Neuro-symbolic AI | Combining learned extraction/guidance with symbolic reasoning (survey level) |
| 1:00–1:10 | Break | — |
| 1:10–1:40 | Evaluating KR systems | Correctness, scalability, explainability as the three axes |
| 1:40–2:00 | Course-map synthesis | How this week's trends relate back to Weeks 1–14 |

### Materials/Equipment
- Slides: knowledge-graph scale diagram, neuro-symbolic architecture sketch, evaluation-axes
  summary
- Starter notebook: knowledge-graph pattern-query skeleton

### Formative Check (in-class)
Exercise: given a small knowledge graph and a 2-hop pattern query, trace the query path by hand;
discuss which of the three evaluation axes a given real-world KR system failure (described by the
instructor) most directly violates.

### Link to Lab/Assessment
Lab 15: Implement a knowledge-graph triple store with pattern queries, and compare it against the
Week 6 semantic network.
