# Presentation: Module 2 — Representation Schemes: Rules, Frames & Ontologies (Weeks 5–7)

**Format:** Slide deck outline for lecture delivery.

1. **Title slide** — Module 2: Representation Schemes: Rules, Frames & Ontologies
2. **Production systems** — working memory, rule base, recognize-act cycle diagram
3. **Forward chaining** — data-driven trace over a general rule base
4. **Backward chaining** — goal-directed trace over the same rule base
5. **A domain-independent engine** — the same code run over two unrelated rule bases
6. **Semantic networks** — IS-A/part-of graph, property inheritance
7. **The exceptions problem** — Tweety/penguin, why strict inheritance fails
8. **Frames** — slots, defaults, inheritance resolution order
9. **Frames fix the exception** — side-by-side with the semantic-network failure
10. **Description logic syntax** — concepts, roles, `⊓, ¬, ∃R.C, ∀R.C`
11. **DL and FOL** — the translation table; why DLs trade expressiveness for decidability
12. **Subsumption** — a toy model-based subsumption checker, worked example
13. **OWL, RDF & the Semantic Web** — triples, standardized DL, real tooling (Protégé, Pellet) as
    context
14. **Module 2 recap** — roadmap into Module 3 (constraints, non-monotonic reasoning, planning)

**Speaker notes:** slide 7's Tweety/penguin failure should be run live (not just shown as a
diagram) so students see the wrong answer actually printed before slide 9 fixes it — this
contrast is the module's single most memorable moment.
