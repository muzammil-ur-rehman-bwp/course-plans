# Capstone Project — Grading Rubric

**Due:** Week 16 | **Weight:** 20% of course grade total (includes proposal, implementation, presentation)

| Component | Weight (of 20%) | Criteria |
|---|---|---|
| Proposal | 2% | Clear problem statement, at least two named formalisms genuinely integrated, sound evaluation plan |
| Implementation — correctness | 6% | Code runs; both (or more) integrated formalisms are correctly implemented and genuinely interact (not merely two unrelated pieces run side by side) |
| Implementation — evaluation | 5% | Evaluation plan from the proposal is actually carried out; results reported honestly, including failure cases |
| Report | 3% | Concise written report: problem, approach, results, 1+ limitation/next step |
| Presentation | 4% | Clear 5–7 min talk; demo or worked example shown; answers Q&A accurately |

## Grading Notes
- A project that honestly reports a technique that didn't fully work (e.g., a partial-order
  planner that cannot resolve a tricky threat, or a frame hierarchy whose defaults conflict under
  multiple inheritance), with sound analysis of why, can score as well as a project that works
  smoothly but is analyzed shallowly.
- The capstone must genuinely **integrate at least two formalisms** from this course, per the
  proposal guidelines — a project where a second formalism is present in name only (e.g., a
  single unused frame bolted onto an otherwise pure rule-based system) does not meet this
  requirement and will be evaluated as if only one formalism were used.
- The capstone must be built on formalisms from this course (logic, rules, frames, description
  logics, CSPs, non-monotonic reasoning, planning, temporal reasoning, Bayesian networks, fuzzy
  logic) — a project built primarily around a scikit-learn or other applied-ML workflow does not
  meet this course's capstone requirement, regardless of how well it performs.
- Pairs must clearly attribute each member's contribution in the report; grading can differ
  between partners if contributions were significantly uneven.
