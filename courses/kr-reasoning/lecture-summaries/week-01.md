# Week 1 Summary — Introduction to Knowledge Representation

**Key takeaways:**
- The KR hypothesis: a system's knowledge-driven behavior must be explainable by an actual,
  causally effective internal structure — representation is not an afterthought.
- Every representation scheme trades off expressiveness, inferential efficiency, and naturalness;
  no scheme maximizes all three.
- This course surveys a deliberately ordered map of schemes (logic → rules → semantic
  networks/frames → description logics → constraints → non-monotonic reasoning → planning →
  temporal/probabilistic reasoning), each motivated by a gap in the previous one.

**You should now be able to:** state the KR hypothesis and the three desiderata; classify a given
representation choice against them; implement and query a simple triple-store knowledge base in
Python.

refutation, and the SAT problem.
