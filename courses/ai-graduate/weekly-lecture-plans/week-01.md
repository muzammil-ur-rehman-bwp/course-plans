# Week 1 Lecture Plan — Artificial Intelligence (Graduate)
## Topic: Graduate AI Overview

**Duration:** 2 hours lecture + 3 hour lab/seminar

### Learning Objectives (Bloom's Level)
1. Recall the undergraduate agent/problem-solving formalism (states, actions, transition model,
   goal test, path cost). (*Remember*)
2. Map the research areas this course covers (advanced search, game theory/multi-agent systems,
   automated reasoning, rigorous planning, MDPs/RL, POMDPs, graphical models, AI complexity,
   research methods) onto the broader AI landscape, and explain how this course's scope is
   disjoint from the sibling graduate ANN/ML/DL/KR&R courses. (*Understand*)
3. Restate the formal definition of a search problem with graduate-level precision. (*Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:15 | Course intro | Syllabus walkthrough, grading, research capstone preview |
| 0:15–0:45 | Research-areas map | Slide walkthrough: where this course sits among the AI-family graduate courses, and what each sibling course owns |
| 0:45–1:20 | Rigorous problem formalism | Board-worked recap: formal definition of a search problem, PEAS revisited with complexity framing |
| 1:20–1:50 | What "graduate rigor" means here | Discussion: reading papers, formal arguments, the research capstone expectations |
| 1:50–2:00 | Q&A | Open floor |

### Materials/Equipment
- Slides: "AI Research Landscape & Course Scope"
- Whiteboard for formal problem-definition recap
- Handout: syllabus + capstone overview

### Formative Check (in-class)
Quick exercise: given a short AI research-question prompt, identify which subfield(s) of this
course's map it belongs to, and name one sibling graduate course it is explicitly NOT about.

### Link to Lab/Assessment
Lab 1: environment setup + formal problem-formulation exercises (see `lab-manuals/lab-01.md`).
No graded assignment this week.
