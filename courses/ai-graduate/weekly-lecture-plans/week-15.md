# Week 15 Lecture Plan — Artificial Intelligence (Graduate)
## Topic: Research Project Work Session

**Duration:** 2 hours lecture/seminar + 3 hour lab (both reallocated to guided project work)

### Learning Objectives (Bloom's Level)
1. Finalize a capstone literature review of 3–5 papers and a sound experiment design.
   (*Apply, Create*)
2. Give and receive structured, specific feedback on a research talk. (*Evaluate*)
3. Revise a draft literature review or experiment plan in response to feedback. (*Create*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:15 | Logistics | Week 16 presentation schedule and format reminder |
| 0:15–1:00 | Guided work block 1 | Literature review / experiment design, instructor circulating for 1:1 check-ins |
| 1:00–1:45 | Practice talk round 1 | Each student/pair gives a 3–4 min compressed practice run |
| 1:45–2:00 | Peer feedback | Structured peer-feedback worksheet exchange |
| 2:00–5:00 (lab block) | Guided work block 2 | Continued experiment/writing time, instructor available for consultation |

### Materials/Equipment
- Peer-feedback structured worksheet (clarity of problem statement, experiment soundness,
  honesty about limitations)
- Each student/pair's own capstone materials and code environment

### Formative Check (in-class)
Each student/pair completes one structured peer-feedback worksheet for another student/pair's
practice talk.

### Link to Lab/Assessment
Lab 15: guided capstone work session, logged via a short work-session note
(see `lab-manuals/lab-15.md`). **Capstone written-paper draft due this week.**
