# Lab Assignment 13 — Structured Paper Critique & Ablation Design (Graded)

**Weight:** part of the weekly Lab Work component (15% of course grade, averaged across all labs).

## Deliverable
Submit the completed worksheet/notebook containing working, correct solutions to Tasks A–D from
`lab-manuals/lab-13.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (claim and evidence clearly and accurately identified) | 2 |
| Task B correct (baseline assessment + at least one genuine reproducibility concern) | 3 |
| Task C correct (ablation design isolates each component, no confounds) | 3 |
| Task D correct (correct numeric comparison and appropriately cautious conclusion) | 2 |
| **Total** | **10** |

## Notes
- Written responses must be specific and reference the actual excerpt/data provided, not generic
  statements.
- Partial credit given for a reasonable but incomplete critique; no credit for a response that
  does not engage with the provided material at all.
