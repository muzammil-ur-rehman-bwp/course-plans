# Week 1 Summary — Graduate AI Overview

**Key takeaways:**
- This course owns advanced search, game theory/multi-agent systems, automated reasoning
  (SAT/SMT), rigorous planning, MDPs/RL fundamentals, POMDPs, AI complexity, and research methods
  — and deliberately does not duplicate the sibling graduate ANN, ML, DL, and KR&R courses.
- A search problem is formally ⟨S, s₀, A, T, G, c⟩; nearly every algorithm this semester operates
  on an instantiation of this tuple or a direct generalization of it.
- Graduate rigor in this course means: correctness arguments for algorithms, naming and using
  real complexity results, and treating research methods (reading/critiquing papers, sound
  experimental design) as a graded skill building toward the Research Capstone.

**You should now be able to:** state the formal definition of a search problem precisely; map a
given AI research question onto this course's subfield map and distinguish it from topics owned
by sibling courses.

**Next week:** Advanced search — IDA*, bidirectional search, and SMA*, with formal time/space
complexity analysis of each relative to plain A*.
