# Lab Assignment 14 — Frontier Paper Mini-Investigation (Graded)

**Weight:** part of the weekly Lab Work component (10% of course grade, averaged across all labs).

## Deliverable
Submit `lab14_frontier_brief.md` containing complete, correct responses to Tasks A–D from
`lab-manuals/lab-14.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A complete (full, correct citation recorded) | 1 |
| Task B correct (problem statement extracted accurately and in the student's own words, passing the precision test) | 3 |
| Task C correct (pillar and open-question-shape mapping, well-justified) | 3 |
| Task D correct (at least 2 evidence-supported claims and 1 speculative claim, each justified specifically) | 3 |
| **Total** | **10** |

## Notes
- The chosen paper must be one the student can properly cite; a critique of a paper without a
  producible citation is not acceptable.
- This lab directly rehearses skills needed for the Paper Critique & Presentation assignment and
  the capstone's related-work survey.
