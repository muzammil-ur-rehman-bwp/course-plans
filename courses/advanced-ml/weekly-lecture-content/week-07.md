# Week 7 — Lecture Content: Nonparametric Bayesian Methods II — The Chinese Restaurant Process

## 1. The Chinese Restaurant Process: Seating Rule
The **Chinese Restaurant Process (CRP)** is the equivalent combinatorial view of the Dirichlet
process, obtained by integrating out the random measure $G$ entirely and describing only the
induced random **partition** of data points into clusters. Picture a restaurant with infinitely
many tables. Customers (data points) arrive one at a time:
- Customer 1 sits at table 1.
- Customer $n+1$, with $n$ customers already seated across tables $1,\dots,K$ holding
  $n_1,\dots,n_K$ customers ($\sum_k n_k = n$), either:
  - joins existing table $k$ with probability $\dfrac{n_k}{n+\alpha}$ (proportional to that
    table's current occupancy — the "rich get richer" effect), or
  - starts a **new** table $K+1$ with probability $\dfrac{\alpha}{n+\alpha}$.
This exactly reproduces the partition structure implied by integrating a DP mixture's cluster
assignments over $G$: each cluster corresponds to a table, and a draw $\theta_k\sim H$ is
associated with table $k$ the moment it is created (so the CRP, plus an $H$-draw per table, is
fully equivalent to the stick-breaking construction's atoms and weights, viewed through the
cluster-assignment lens rather than the weight/atom lens).

## 2. Exchangeability
A random partition (or, more generally, a sequence of random variables) is **exchangeable** if its
joint distribution is invariant under any permutation of the data points' arrival order. The CRP's
induced partition distribution is exchangeable: the *probability of a given partition* (which
points end up grouped together, ignoring table labels and the order points joined) depends only on
the sizes of the resulting groups, not on which customer happened to arrive in which order. This
can be verified directly: the probability of any specific seating sequence leading to a partition
with block sizes $n_1,\dots,n_K$ is
```
P(sequence) = α^K · (n_1−1)! (n_2−1)! ⋯ (n_K−1)! / ( α(α+1)⋯(α+n−1) )
```
(each factor $(n_k-1)!$ arises from the product of consecutive join-probabilities $1/(j+\alpha),
2/(j+\alpha),\dots$ building up table $k$, and the denominator is the product of all
$n+\alpha,\dots$-type normalizers across all $n$ arrivals), which depends on the data only through
the multiset of block sizes $\{n_1,\dots,n_K\}$ — not on arrival order. **Why this matters for
inference:** a real dataset has no inherent "arrival order" — exchangeability is exactly the
property that licenses treating the data as if generated by a CRP (or any other exchangeable
process) regardless of the (arbitrary) order it happens to be stored or processed in, which is a
basic correctness requirement for any valid Bayesian model of unordered exchangeable data (the
same role de Finetti's theorem plays for i.i.d. sequences, now one level up, for partitions).

## 3. Growth in the Number of Occupied Tables
Let $K_n$ be the number of occupied tables after $n$ customers. At step $n+1$, a new table is
started with probability exactly $\alpha/(n+\alpha)$, so
```
E[K_n] = Σ_{j=0}^{n-1} α/(j+α) = α Σ_{j=0}^{n-1} 1/(j+α)
```
Since $\sum_{j=0}^{n-1} 1/(j+\alpha) = \ln n + O(1)$ (a harmonic-sum-style asymptotic, directly
analogous to $\sum_{j=1}^n 1/j = \ln n + O(1)$), we get
```
E[K_n] = α ln n + O(α)  =  O(α log n)
```
This is the formal sense in which a CRP/DP mixture's effective number of clusters grows — slowly,
logarithmically — with more data, rather than being fixed in advance: more data can reveal more
structure (more clusters), but only at a logarithmic rate, controlled directly by $\alpha$,
matching Week 6's qualitative description of $\alpha$'s role exactly.

## 4. Building a DP Mixture Model from the CRP
A full **Dirichlet process mixture model** combines the CRP's partition structure with a
likelihood: each table $k$ is assigned a parameter $\theta_k\sim H$ (the base measure) the moment
it is created, and each customer seated at table $k$ generates its observation $x_i \sim
F(\cdot\mid\theta_k)$ for some parametric likelihood family $F$ (e.g., $F(\cdot\mid\theta_k) =
\mathcal N(\theta_k, \sigma^2)$ for a fixed noise variance). This gives a fully specified
generative model for data with an unknown, data-driven number of clusters — for any *finite* $n$,
almost surely only finitely many tables are occupied (by §3), even though the underlying DP prior
has support on partitions with arbitrarily many clusters.

**Inference sketch.** The standard computational approach is a collapsed Gibbs sampler: iterate
over each data point $i$, remove it from its current table, and resample its table assignment from
the conditional distribution — join existing table $k$ with probability proportional to
$n_k^{(-i)} \cdot F(x_i\mid\theta_k)$ (CRP seating weight times how well point $i$ fits that
table's existing parameter), or start a new table with probability proportional to
$\alpha \cdot \int F(x_i\mid\theta)\,dH(\theta)$ (CRP new-table weight times the marginal
likelihood of $x_i$ under a fresh draw from $H$) — repeating until the sampler converges. This is
presented here at the conceptual level only; a full working Gibbs sampler is beyond this course's
scope and belongs to a dedicated Bayesian-nonparametrics research track.

## 5. Python: A CRP Sampler and an Infinite Gaussian Mixture Generator
```python
import numpy as np

def crp_sample(n, alpha, rng):
    """Returns a length-n array of table assignments (0-indexed) generated by the CRP."""
    assignments = np.zeros(n, dtype=int)
    table_counts = [1]   # customer 0 starts table 0
    for i in range(1, n):
        probs = np.array(table_counts + [alpha]) / (i + alpha)
        choice = rng.choice(len(probs), p=probs)
        if choice == len(table_counts):
            table_counts.append(1)
        else:
            table_counts[choice] += 1
        assignments[i] = choice
    return assignments, table_counts

rng = np.random.default_rng(0)
for alpha in [0.5, 2.0, 5.0]:
    n = 2000
    assignments, table_counts = crp_sample(n, alpha, rng)
    k_n = len(table_counts)
    predicted = alpha * np.log(n)
    print(f"alpha={alpha:4.1f}  observed K_n={k_n:4d}  predicted alpha*log(n)={predicted:6.2f}")

def crp_gaussian_mixture(n, alpha, H_scale, obs_noise, rng):
    assignments, table_counts = crp_sample(n, alpha, rng)
    thetas = rng.normal(0.0, H_scale, size=len(table_counts))
    x = thetas[assignments] + rng.normal(0.0, obs_noise, size=n)
    return x, assignments
```
The observed $K_n$ should track the $\alpha\log n$ prediction's order of magnitude (exact
agreement is not expected for a single run — the formula is an expectation — but the scaling with
$\alpha$ should be clearly visible across repeated runs or larger $n$).
