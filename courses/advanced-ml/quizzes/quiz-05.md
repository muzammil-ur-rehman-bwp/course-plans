# Quiz 5 — Instrumental Variables & the Do-Calculus (Week 10)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of
Quizzes (10%, best 5 of 6 counted)

1. State the three assumptions required for a variable $Z$ to be a valid instrument. (2 pts)
2. Derive the linear-IV identification formula $\beta=\mathrm{Cov}(Z,Y)/\mathrm{Cov}(Z,T)$ in
   two lines, starting from $\mathrm{Cov}(Z,Y)$. (2 pts)
3. State do-calculus Rule 2 (action/observation exchange) precisely, including the required graph
   modification. (2 pts)
4. For the graph $X\leftarrow Z\to Y$, $X\to Y$, state the back-door adjustment formula for
   $P(y\mid\mathrm{do}(x))$ and name which rule justifies the final exchange step. (2 pts)
5. A colleague claims: "Since do-calculus is complete, it can always find an adjustment set for
   any confounded graph, even with an unobserved confounder." Identify what is wrong with this
   claim, referencing the Week 9 non-identifiable worked example. (2 pts)

before the quiz).**
