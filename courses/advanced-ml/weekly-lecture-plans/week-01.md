# Week 1 Lecture Plan — Advanced Machine Learning (Post Graduate)
## Topic: Postgraduate Overview — The Statistical-Learning-Theory Research Frontier

**Duration:** 2 hours lecture + 3 hour research seminar/lab

### Learning Objectives (Bloom's Level)
1. Recall the graduate-ML formalism this course assumes and state it is not re-taught. (*Remember*)
2. State the five research pillars this course covers and map them against the sibling
   postgraduate courses, in particular distinguishing full-information OCO from *Advanced
   Artificial Intelligence*'s bandit territory. (*Understand*)
3. State, in one sentence each, the four components of a research proposal. (*Remember, Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | Course framing | Why postgraduate ML theory: from "applying/analyzing known tools" to "formulating open questions" |
| 0:20–0:50 | The five pillars | Minimax/high-dim stats; full-information OCO; nonparametric Bayes; causal inference in depth; trustworthy/robust ML — mapped against assumed graduate content |
| 0:50–1:10 | Scope boundary vs. sibling courses | Explicit contrast: this course's full-information OCO (Week 5) vs. *Advanced AI*'s bandit/regret theory |
| 1:10–1:40 | Diagnostic self-check | Walk the assumed-foundations checklist (PAC/VC/Rademacher, concentration, convex opt/KKT, kernels/RKHS, ensembles, Bayesian ML, CRFs, dimensionality reduction, causal-inference intro, model selection) |
| 1:40–2:00 | Research-proposal preview | One slide each on problem statement, related-work survey, proposed approach, feasibility argument |

### Materials/Equipment
- Slides: "Advanced Machine Learning: Course Map and Research Frontier"
- Diagnostic self-check handout (assumed graduate-ML topics)
- Live-coding environment (Jupyter) for setup verification

### Formative Check (in-class)
Given five research-question prompts, identify which of the five pillars each belongs to and name
one graduate-ML topic it assumes as background without re-deriving it.
