# Quiz 6 — Recursion & Encapsulation (Week 13)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What are the two required parts of every correct recursive method? (2 pts)
2. What specifically goes wrong if a recursive method's base case is missing or unreachable?
   (2 pts)
3. What is encapsulation, and why is making a class's fields `private` a part of it? (2 pts)
4. What is the difference between a `static` field and an instance field? (2 pts)
5. Given the following, what value does `factorial(3)` return, and why?
   ```java
   static int factorial(int n) {
       if (n <= 1) return 1;
       return n * factorial(n - 1);
   }
   ```
   (2 pts)
