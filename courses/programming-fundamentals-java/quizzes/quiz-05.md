# Quiz 5 — Classes, `ArrayList` & File I/O (Week 11)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. By default, are the fields of a Java `class` public or private if no access modifier is
   written? (1 pt)
2. Given `class Point { int x; int y; }`, write a line of code that creates a `Point` named
   `origin` using `new` (assume a constructor exists taking `x` and `y`). (2 pts)
3. What must you do when opening a file in Java that might not exist, and what exception type
   must be handled? (2 pts)
4. What is the difference between reading with `scanner.next()` and
   `bufferedReader.readLine()`? (2 pts)
5. What does `.get(i)` on an `ArrayList` correspond to for a plain array, and what does
   `.size()` correspond to? (3 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
