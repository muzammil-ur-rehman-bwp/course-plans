# Quiz 1 — Java Basics (Week 2)

**Duration:** 15 minutes | **Format:** 5 short-answer/code questions | **Weight:** part of Quizzes (10%, best 5 of 6 counted)

1. What are the two stages a Java source file goes through before it runs, and what tool
   performs each? (2 pts)
2. What is wrong with the following code, and what is the safest fix?
   ```java
   int total;
   total = total + 5;
   System.out.println(total);
   ```
   (2 pts)
3. Give the Java type you would use to store each of: a person's age, a product's price, a
   single letter grade, and whether a user is logged in. (2 pts)
4. What does `input.nextInt();` followed by `input.nextInt();` do if the user types `3 4` and
   presses Enter? (2 pts)
5. Explain, in one sentence, why every Java `.java` file's name must match its public class
   name. (2 pts)

**Answer key available to instructors in the course LMS gradebook (not distributed to students
before the quiz).**
