# Presentation: Module 1 — Java Foundations (Weeks 1–4)

**Format:** Slide deck outline for lecture delivery (convert to slides in institution's template).

1. **Title slide** — Programming Fundamentals (Java): Module 1, Java Foundations
2. **The compile-run model on the JVM** — diagram: source → `javac` → bytecode → JVM (`java`)
3. **Your first program** — `class`, `main`, `System.out`/`Scanner` (code snippet slide)
4. **Primitive types** — `int`/`double`/`char`/`boolean` comparison table
5. **Operators** — arithmetic/relational/logical operator cheat-sheet
6. **Type conversion** — implicit widening vs. explicit casting, integer-division trap
7. **Control flow** — `if`/`else if`/`else` and `switch` (including arrow-form), dangling-`else` warning
8. **Loops** — `for` vs. `while` vs. `do-while` comparison table
9. **Common pitfalls** — uninitialized variables, off-by-one, infinite loops (checklist slide)
10. **Module 1 recap** — key skills checklist
11. **Looking ahead** — "Next: methods — decomposing programs" teaser slide

**Speaker notes:** this module is infrastructure — every later module assumes comfort compiling,
running, and reading compiler errors, so invest lecture time in live-coding over slide-reading.
