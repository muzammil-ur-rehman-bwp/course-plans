# Week 16 Summary — Capstone Presentations, Course Review

**Key takeaways:**
- The semester moved deliberately from Java basics through control flow, methods, arrays/strings,
  objects/references, classes, collections, file I/O, recursion, encapsulation, and algorithms —
  each week building directly on the last.
- The capstone project is, in essence, "all of the above" applied to one real problem: arrays or
  `ArrayList`s for storage, classes for organization, methods for structure, and file I/O for
  persistence.
- The class basics from Weeks 9 and 13 preview the Object-Oriented Programming course
  (inheritance, polymorphism, interfaces); the array/efficiency intuition from Weeks 6–7 and 14
  previews Data Structures & Algorithms.

**You should now be able to:** present and explain an original Java console application;
articulate how each week's topic depended on earlier ones; describe what the next two courses in
the sequence will add.
