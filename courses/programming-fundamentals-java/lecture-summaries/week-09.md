# Week 9 Summary — Midterm Exam + Classes and Objects

**Key takeaways:**
- The midterm covered Weeks 1–8: basics, operators, control flow, loops, methods, arrays,
  strings, and objects/references.
- A class groups related fields (data) and methods (behavior) into one user-defined type; a
  constructor initializes a new object's fields when it is created with `new`.
- `this` refers to the object the current method/constructor call is running on, distinguishing a
  field from a same-named parameter.
- Each object created from a class has its own independent copies of its instance fields.

**You should now be able to:** define a simple class with fields, a constructor, and methods;
create and use multiple independent objects of that class.
