# Week 10 Lecture Plan — Programming Fundamentals (Java)
## Topic: Using Existing Classes/APIs

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the core `ArrayList<T>` operations (`add`, `get`, `set`, `remove`, `size`). (*Remember*)
2. Explain autoboxing and the relationship between a primitive type and its wrapper class. (*Understand*)
3. Apply `ArrayList` in place of a raw array when a collection needs to grow or shrink. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | Why `ArrayList`? | Fixed-size array limitation motivation |
| 0:30–1:05 | `ArrayList` operations | Live-coded demo: `add`, `get`, `set`, `remove`, `size`, `for-each` |
| 1:05–1:30 | Wrapper classes & autoboxing | `Integer`, `Double`, `Character`, `Boolean`; boxing/unboxing |
| 1:30–2:00 | `ArrayList` vs. array | Side-by-side comparison; converting between the two |

### Materials/Equipment
- Slides: "Collections: `ArrayList` and Wrapper Classes"
- Live-coding environment

### Formative Check (in-class)
Quick exercise: rewrite a fixed-size-array version of a "add scores until the user types done"
program using `ArrayList<Integer>` instead.
