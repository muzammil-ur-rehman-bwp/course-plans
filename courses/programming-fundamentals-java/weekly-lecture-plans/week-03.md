# Week 3 Lecture Plan — Programming Fundamentals (Java)
## Topic: Control Flow: `if`/`else`, `switch`

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the syntax of `if`/`else if`/`else` and `switch`. (*Remember*)
2. Explain how nested conditionals and `switch` fall-through behave. (*Understand*)
3. Apply branching constructs to translate a decision table into correct code. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:20 | Boolean expressions | Review of relational/logical operators as conditions |
| 0:20–0:50 | `if`/`else if`/`else` | Live-coded demo; nested conditionals; dangling-`else` pitfall |
| 0:50–1:25 | `switch` statement | Live-coded demo: `break`/fall-through; traditional vs. arrow-form `switch` |
| 1:25–1:45 | Ternary operator | Short worked examples |
| 1:45–2:00 | Decision tables | Translating a grading-band decision table into code |

### Materials/Equipment
- Slides: "Control Flow in Java"
- Live-coding environment

### Formative Check (in-class)
Quick exercise: write an `if`/`else if`/`else` chain assigning a letter grade from a numeric
score, then rewrite an equivalent menu-choice example using `switch`.

### Link to Lab/Assessment
Lab 3: Control flow practice (see `lab-manuals/lab-03.md`). No graded assignment this week.
