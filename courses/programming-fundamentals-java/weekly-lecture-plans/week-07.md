# Week 7 Lecture Plan — Programming Fundamentals (Java)
## Topic: 2D Arrays and Strings

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall 2D array declaration and indexing as an array of arrays. (*Remember*)
2. Explain `String` immutability and why `==` is unreliable for comparing `String` content. (*Understand*)
3. Apply nested loops to process a matrix, and `String`/`StringBuilder` methods to manipulate text. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | 2D arrays | Live-coded demo: declaration, indexing, nested loops over a matrix |
| 0:30–1:00 | Matrix processing | Row/column sums (live-coded) |
| 1:00–1:20 | `String` basics | Immutability; `length`, `charAt`, `substring`, `indexOf` |
| 1:20–1:45 | `==` vs. `.equals()` | Live demo of the classic `String` comparison pitfall |
| 1:45–2:00 | `StringBuilder` | Efficient concatenation in a loop vs. repeated `+` |

### Materials/Equipment
- Slides: "2D Arrays and Strings in Java"
- Live-coding environment

### Formative Check (in-class)
Quick exercise: predict the output of comparing two `String`s built differently with `==` vs.
`.equals()`, then verify by running the code.
