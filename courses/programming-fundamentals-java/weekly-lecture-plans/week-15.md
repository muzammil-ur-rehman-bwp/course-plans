# Week 15 Lecture Plan — Programming Fundamentals (Java)
## Topic: Debugging, Testing, and Program Design/Style

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall how to read a Java stack trace to locate the source of an exception. (*Remember*)
2. Explain the use of breakpoints, stepping, and watches in a debugger. (*Understand*)
3. Analyze a buggy program using the debugger and stack traces to find the defect. (*Analyze*)
4. Evaluate a working program's style and refactor it for clarity and better encapsulation. (*Evaluate*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Reading stack traces | Live demo: triggering and reading a `NullPointerException` trace |
| 0:25–1:00 | Using a debugger | Live demo: breakpoints, stepping, watching variables (IDE debugger) |
| 1:00–1:30 | Defensive programming | Input validation; `assert` statements |
| 1:30–2:00 | Testing mindset & style | Writing small hand-checked test cases; refactoring for clarity |

### Materials/Equipment
- Slides: "Debugging and Testing in Java"
- Provided buggy sample program

### Formative Check (in-class)
Quick exercise: given a stack trace from a provided buggy program, identify the line and the
likely cause before opening the debugger to confirm.
