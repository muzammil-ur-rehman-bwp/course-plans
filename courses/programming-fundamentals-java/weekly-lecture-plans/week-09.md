# Week 9 Lecture Plan — Programming Fundamentals (Java)
## Topic: Midterm Exam + Classes and Objects

**Duration:** 2 hours lecture + 3 hour lab (exam occupies part of lecture time)

### Learning Objectives (Bloom's Level)
1. Demonstrate recall and application of Weeks 1–8 material under exam conditions. (*Remember, Apply*)
2. Explain the role of fields, constructors, and methods in a class. (*Understand*)
3. Define a simple class and create/use instances of it. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:00 | **Midterm Exam** | Closed-book/open-notes per instructor policy, covers Weeks 1–8 |
| 1:00–1:10 | Break | — |
| 1:10–1:35 | Defining a class | Live-coded demo: fields, a constructor, methods |
| 1:35–2:00 | Creating objects | `new`, calling methods on an instance, multiple instances |

### Materials/Equipment
- Midterm exam paper/online quiz
- Slides: "Your First Java Class"

### Formative Check (in-class)
Post-exam discussion: given a simple class with two fields, write a constructor that initializes
both and a method that prints them.
