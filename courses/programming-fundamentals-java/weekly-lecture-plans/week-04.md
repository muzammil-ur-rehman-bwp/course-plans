# Week 4 Lecture Plan — Programming Fundamentals (Java)
## Topic: Loops: `for`, `while`, `do-while`

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the syntax and semantics of `for`, `while`, and `do-while` loops. (*Remember*)
2. Explain when each loop construct, and `break`/`continue`, are most appropriate. (*Understand*)
3. Apply loops to implement counting, accumulation, and sentinel-controlled input patterns. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | `for` loops | Live-coded demo: counter-controlled iteration |
| 0:25–0:50 | `while`/`do-while` | Live-coded demo: sentinel-controlled input loop |
| 0:50–1:15 | `break`/`continue` | Worked examples; nested loops |
| 1:15–1:45 | Common patterns | Accumulation, counting, searching with a loop |
| 1:45–2:00 | Pitfalls | Off-by-one errors; infinite loops; how to spot and fix both |

### Materials/Equipment
- Slides: "Loops in Java"
- Live-coding environment

### Formative Check (in-class)
Quick exercise: write a sentinel-controlled loop that reads integers until `-1` is entered and
prints their running total and count.
