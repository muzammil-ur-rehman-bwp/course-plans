# Week 2 Lecture Plan — Programming Fundamentals (Java)
## Topic: Operators, Expressions, and Type Conversion

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall Java's arithmetic, relational, logical, and assignment operators. (*Remember*)
2. Explain operator precedence and the difference between implicit widening and explicit casting. (*Understand*)
3. Apply explicit casts to write expressions that compute correctly, and distinguish primitive from reference types. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:25 | Operators | Live-coded demo: arithmetic, relational, logical, assignment operators |
| 0:25–0:45 | Precedence & increment/decrement | Worked examples; common precedence traps |
| 0:45–1:20 | Type conversion | Implicit widening vs. explicit casting (`(double) a / b`); integer-division trap |
| 1:20–1:45 | Overflow & precision | `int` overflow demo; floating-point rounding demo |
| 1:45–2:00 | Primitive vs. reference types | Conceptual preview: `int` vs. `String`/arrays as references |

### Materials/Equipment
- Slides: "Operators, Expressions, and Type Conversion in Java"
- Live-coding environment

### Formative Check (in-class)
Quick exercise: given `int a = 7, b = 2;`, predict the output of `a / b` and `(double) a / b`,
then verify by running the code.
