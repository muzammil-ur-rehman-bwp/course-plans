# Week 1 Lecture Plan — Programming Fundamentals (Java)
## Topic: Intro to Programming & Java Basics

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall what a program is and describe how Java is compiled and run on the JVM. (*Remember*)
2. Explain the role of `class`, `main`, `System.out`, and `Scanner` in a minimal Java program. (*Understand*)
3. Write and compile a simple Java program that declares variables of primitive types and performs basic I/O. (*Apply*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:10 | Course intro | Syllabus walkthrough, grading, capstone preview |
| 0:10–0:30 | What is a program? | Compile (`javac`) → bytecode → run on the JVM (`java`); live demo |
| 0:30–1:00 | First Java program | Live-coded demo: `class`, `public static void main(String[] args)`, `System.out.println` |
| 1:00–1:40 | Variables & primitive types | Live-coded demo: `int`, `double`, `char`, `boolean`; declaration/initialization |
| 1:40–2:00 | Basic I/O | Live-coded demo: `Scanner`, reading user input |

### Materials/Equipment
- Slides: "Compiling and Running Your First Java Program"
- Live-coding environment (IntelliJ IDEA or VS Code + terminal)
- Handout: Java syntax quick-reference cheat sheet

### Formative Check (in-class)
Quick exercise: write a program that declares an `int` and a `double`, reads both from the user
with `Scanner`, and prints their sum.

### Link to Lab/Assessment
Lab 1: Compiling and running basic Java programs (see `lab-manuals/lab-01.md`). No graded
assignment this week.
