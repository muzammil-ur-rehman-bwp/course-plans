# Week 8 Lecture Plan — Programming Fundamentals (Java)
## Topic: Intro to Objects & References; Midterm Review

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall that a variable of a reference type holds a reference to an object, not the object itself. (*Remember*)
2. Explain `null`, the stack/heap model, and `==` vs. `.equals()` for objects in general. (*Understand*)
3. Analyze and trace reference diagrams for simple programs involving arrays and `String`s. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | References, `null` | Live-coded demo: two references to one array; `null` and `NullPointerException` |
| 0:30–1:00 | Stack vs. heap | Conceptual diagram: local variables vs. objects they reference |
| 1:00–1:20 | `==` vs. `.equals()` revisited | General object-equality rule, beyond `String` |
| 1:20–2:00 | Midterm review | Practice problems spanning Weeks 1–7 |

### Materials/Equipment
- Slides: "References, `null`, and the Stack/Heap Model"
- Midterm practice problem set (handout)

### Formative Check (in-class)
Quick exercise: given two variables assigned the same array reference, predict the effect of
mutating an element through one variable on what the other variable sees.
