# Week 14 Lecture Plan — Programming Fundamentals (Java)
## Topic: Sorting & Searching Algorithms

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Recall the steps of bubble sort, selection sort, and binary search. (*Remember*)
2. Explain why binary search requires a sorted array. (*Understand*)
3. Apply these algorithms by implementing them from scratch on `int[]` arrays. (*Apply*)
4. Analyze and informally compare the number of comparisons/swaps each algorithm performs. (*Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:30 | Bubble sort | Live-coded demo; step-by-step trace on a small array |
| 0:30–1:00 | Selection sort | Live-coded demo; step-by-step trace |
| 1:00–1:25 | Linear search | Baseline search for comparison |
| 1:25–1:55 | Binary search | Live-coded demo on a sorted array; halving-the-problem diagram |
| 1:55–2:00 | Informal efficiency | Comparison counts; intuition for why binary search scales better |

### Materials/Equipment
- Slides: "Sorting and Searching in Java"
- Trace diagram handout

### Formative Check (in-class)
Quick exercise: trace selection sort by hand on `{5, 2, 8, 1, 9}` for the first two passes, then
binary-search the sorted result for `8`.
