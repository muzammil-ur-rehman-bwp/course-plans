# Lab Manual 7 — 2D Arrays and Strings

**Duration:** 3 hours | **Prerequisite:** Week 7 lecture

## Objectives
Practice processing 2D arrays and using `String`/`StringBuilder` methods.

## Setup
Create `Lab07.java` in your working folder.

## Procedure
1. **Task A — Matrix sums:** create a `3x3` `int[][]` grid filled with user input, and print the
   sum of each row and each column.
2. **Task B — `String` methods:** read a sentence from the user and print its length, its first
   and last characters, and whether it contains the word `"Java"` (using `indexOf`, case-
   insensitively).
3. **Task C — `==` vs. `.equals()`:** construct two `String`s with identical content using
   `new String(...)`, compare them with both `==` and `.equals()`, and explain the (different)
   results in a comment.
4. **Task D — Mini-challenge:** use a `StringBuilder` to build and print a comma-separated list
   of the numbers 1–20.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab07.java` via the course submission system by the end of the lab session.
