# Lab Manual 1 — Java Basics

**Duration:** 3 hours | **Prerequisite:** Week 1 lecture

## Objectives
Practice compiling and running Java programs, and using variables, primitive types, and basic
I/O.

## Setup
1. Confirm a JDK is available: `javac --version` (or `java --version`); must be JDK 17+.
2. Create a working folder `lab01/` and open it in IntelliJ IDEA (or VS Code).
3. Create `Lab01.java` with `public class Lab01 { ... }`.

## Procedure
1. **Task A — Hello, World:** write and compile a program that prints `"Hello, Java!"`. Verify it
   compiles with `javac Lab01.java` and runs with `java Lab01`.
2. **Task B — Variables:** declare an `int`, a `double`, a `char`, and a `boolean`, initialize
   each, and print all four with labels.
3. **Task C — Basic I/O:** read a rectangle's `width` and `height` (as `double`) from the user
   with `Scanner`, compute the area and perimeter, and print both with labels.
4. **Task D — Mini-challenge:** read a temperature in Celsius from the user and print the
   Fahrenheit equivalent (`F = C * 9.0 / 5.0 + 32.0`).

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab01.java` via the course submission system by the end of the lab session (or per
instructor-announced deadline).
