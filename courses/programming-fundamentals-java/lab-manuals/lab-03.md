# Lab Manual 3 — Control Flow

**Duration:** 3 hours | **Prerequisite:** Week 3 lecture

## Objectives
Practice writing `if`/`else if`/`else` chains and `switch` statements.

## Setup
Create `Lab03.java` in your working folder.

## Procedure
1. **Task A — Letter grade:** read a numeric score and print its letter grade (A ≥ 85, B ≥ 70,
   C ≥ 55, D ≥ 40, F otherwise) using `if`/`else if`/`else`.
2. **Task B — Menu with `switch`:** read an integer menu choice (1–4) and print the matching
   action name (`Add`, `Subtract`, `Multiply`, `Divide`) using a traditional `switch` with
   `break`, plus a `default` for invalid input.
3. **Task C — Arrow-form `switch`:** rewrite Task B as a Java 14+ arrow-form `switch` expression
   that returns the action name directly.
4. **Task D — Mini-challenge:** write a short program that prints `"Even"`/`"Odd"` and
   `"Positive"`/`"Negative"`/`"Zero"` for a read integer, using the ternary operator for at least
   one of the two outputs.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab03.java` via the course submission system by the end of the lab session.
