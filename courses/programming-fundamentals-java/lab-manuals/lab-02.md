# Lab Manual 2 — Operators and Expressions

**Duration:** 3 hours | **Prerequisite:** Week 2 lecture

## Objectives
Practice using arithmetic, relational, and logical operators, and performing correct type
conversion.

## Setup
Create `Lab02.java` in your working folder.

## Procedure
1. **Task A — Arithmetic:** read two integers from the user, print their sum, difference,
   product, integer quotient, and remainder, each with a label.
2. **Task B — The casting trap:** given the two integers from Task A, print their quotient as a
   `double` using an explicit cast, and explain in a comment why the cast must be applied before
   the division.
3. **Task C — Relational/logical:** read a third integer, and print whether all three integers
   are positive, using a single `if` with logical `&&`.
4. **Task D — Mini-challenge:** demonstrate `int` overflow by printing `Integer.MAX_VALUE + 1`,
   and explain the result in a comment.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab02.java` via the course submission system by the end of the lab session.
