# Lab Manual 10 — `ArrayList`

**Duration:** 3 hours | **Prerequisite:** Week 10 lecture

## Objectives
Practice using `ArrayList` and wrapper classes in place of raw arrays.

## Setup
Create `Lab10.java` in your working folder.

## Procedure
1. **Task A — Build a list:** create an `ArrayList<String>`, add 5 names read from the user, and
   print the list with a `for-each` loop.
2. **Task B — Modify the list:** remove one specific name (by value, using `.remove(Object)`),
   replace another using `.set`, and print the list's `size()` before and after.
3. **Task C — `ArrayList<Integer>`:** build an `ArrayList<Integer>` of scores read until a
   sentinel is entered, and compute the average using `.size()` and a loop (demonstrating
   autoboxing/unboxing in action).
4. **Task D — Mini-challenge:** convert the `ArrayList<Integer>` from Task C into a plain
   `int[]` by copying each element over in a loop, and print the array to confirm the contents
   match.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab10.java` via the course submission system by the end of the lab session.
