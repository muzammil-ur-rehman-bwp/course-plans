# Lab Manual 14 — Sorting and Searching

**Duration:** 3 hours | **Prerequisite:** Week 14 lecture

## Objectives
Practice implementing and tracing bubble sort, selection sort, linear search, and binary search.

## Setup
Create `Lab14.java` in your working folder.

## Procedure
1. **Task A — Bubble sort:** implement `static void bubbleSort(int[] values)` and use it to sort
   an array of at least 10 user-entered integers; print before and after.
2. **Task B — Selection sort:** implement `static void selectionSort(int[] values)`; run it on a
   fresh copy of the same input and confirm it produces the same sorted result as Task A.
3. **Task C — Linear vs. binary search:** implement both `linearSearch` and `binarySearch`; using
   the sorted array, search for one value guaranteed present and two likely absent with each
   method, and print all results.
4. **Task D — Mini-challenge:** count and print the number of comparisons each search method
   performs for the same target, illustrating binary search's efficiency advantage.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab14.java` via the course submission system by the end of the lab session.
