# Lab Manual 6 — 1D Arrays

**Duration:** 3 hours | **Prerequisite:** Week 6 lecture

## Objectives
Practice declaring, filling, iterating, and processing 1D arrays.

## Setup
Create `Lab06.java` in your working folder.

## Procedure
1. **Task A — Fill and print:** create an `int[]` of size 10, fill it with user input, and print
   it using a `for-each` loop.
2. **Task B — Aggregates:** write methods `sum`, `max`, `min`, and `average` for an `int[]`, and
   call all four on the array from Task A.
3. **Task C — Mutating through a method:** write `static void doubleAll(int[] values)` that
   doubles every element in place, and demonstrate that the caller's array reflects the change
   after the call.
4. **Task D — Mini-challenge:** deliberately trigger an `ArrayIndexOutOfBoundsException` by
   accessing one index past the end, observe the exception message, then fix the bug.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output (Task D's exception should be shown as a comment with the fix applied
in the final submitted code).

## Submission
Submit `Lab06.java` via the course submission system by the end of the lab session.
