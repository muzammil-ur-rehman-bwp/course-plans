# Lab Manual 4 — Loops

**Duration:** 3 hours | **Prerequisite:** Week 4 lecture

## Objectives
Practice `for`, `while`, and `do-while` loops, and sentinel-controlled input.

## Setup
Create `Lab04.java` in your working folder.

## Procedure
1. **Task A — Counting with `for`:** print the numbers 1 through 20, five per line, using a `for`
   loop.
2. **Task B — Sentinel-controlled input:** use a `while` loop to read integers until `-1` is
   entered, printing the running total and count after each number, then the final average
   (guarding against division by zero).
3. **Task C — Menu with `do-while`:** build a simple menu loop (`do-while`) that repeatedly
   displays options and reads a choice, exiting only when the user selects "Quit."
4. **Task D — Mini-challenge:** use nested `for` loops to print a multiplication table (1–10) as
   a grid.

## Expected Output
A single source file with four clearly labeled sections (A–D), each compiling cleanly and
producing correct output.

## Submission
Submit `Lab04.java` via the course submission system by the end of the lab session.
