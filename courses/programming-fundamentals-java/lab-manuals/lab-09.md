# Lab Manual 9 — Classes and Objects Basics

**Duration:** 3 hours (lighter session given the midterm earlier in the week) | **Prerequisite:** Week 9 lecture

## Objectives
Practice defining a simple class and creating/using objects of it.

## Setup
Create `Lab09.java` in your working folder.

## Procedure
1. **Task A — Define a class:** define a class `Point` with `int x` and `int y` fields, a
   constructor that sets both, and a method `printLocation()` that prints `"(x, y)"`.
2. **Task B — Create objects:** create at least 3 different `Point` objects in `main` and print
   each one's location.
3. **Task C — Reflection:** in a comment block, explain in your own words why each `Point` object
   has its own independent `x` and `y`, even though they were all created from the same class.

## Expected Output
A single source file with Tasks A–B compiling cleanly and running correctly; Task C's
explanation as a comment.

## Submission
Submit `Lab09.java` by the end of the lab session.
