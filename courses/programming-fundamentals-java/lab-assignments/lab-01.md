# Lab Assignment 1 — Java Basics (Graded)

**Weight:** part of the weekly Lab Work component (20% of course grade, averaged across all labs).

## Deliverable
Submit `Lab01.java` containing working, correct solutions to Tasks A–D from
`lab-manuals/lab-01.md`.

## Grading Rubric
| Criterion | Points |
|---|---|
| Task A correct (Hello, World compiles & runs) | 1 |
| Task B correct (four typed, initialized variables printed) | 2 |
| Task C correct (area/perimeter from user input) | 4 |
| Task D correct (Celsius-to-Fahrenheit conversion) | 3 |
| **Total** | **10** |

## Notes
- Code must compile cleanly with `javac`. Partial credit is given for logically sound but buggy
  attempts; no credit for code that does not compile at all.
- File name must exactly match the public class name (`Lab01.java`).
