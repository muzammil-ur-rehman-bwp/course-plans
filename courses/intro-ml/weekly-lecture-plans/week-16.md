# Week 16 Lecture Plan — Introduction to Machine Learning
## Topic: Capstone Presentations & Course Review

**Duration:** 2 hours lecture + 3 hour lab (used for presentations)

### Learning Objectives (Bloom's Level)
1. Evaluate peers' capstone projects using the course's evaluation standards. (*Evaluate*)
2. Present an original end-to-end ML project, justifying model and metric choices. (*Create,
   Evaluate*)
3. Recall and synthesize the course's full map of techniques. (*Remember, Understand*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–0:15 | Course review | Recap: regression → classification → ensembles → SVMs → evaluation → feature engineering → unsupervised learning → recommenders → systems practice |
| 0:15–0:25 | Where this course ends | Pointer to the dedicated Deep Learning / Neural Networks courses for the next step |
| 0:25–2:00 (and lab session) | Capstone presentations | Student presentations (5–7 min + Q&A each), per `presentations/capstone-presentation-template.md` |

### Materials/Equipment
- Presentation equipment; grading rubric (`assignments/capstone-rubric.md`) for instructor use
  during talks.

### Formative Check (in-class)
Peer evaluation: each student completes a short peer-feedback form for at least two other
presentations, naming one strength and one question.

### Link to Lab/Assessment
No new lab this week — the lab session is used for capstone presentations. Capstone final
submission and presentation are due this week (20% of course grade).
