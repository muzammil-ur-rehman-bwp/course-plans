# Week 9 Lecture Plan — Introduction to Machine Learning
## Topic: Midterm Exam + Support Vector Machines

**Duration:** 2 hours lecture + 3 hour lab

### Learning Objectives (Bloom's Level)
1. Demonstrate recall and application of Weeks 1–8 material in the midterm exam. (*Remember,
   Apply*)
2. Explain margin maximization and support vectors in SVM classification. (*Understand*)
3. Apply the kernel trick (linear, polynomial, RBF) and soft-margin SVMs to non-linearly
   separable data. (*Apply, Analyze*)

### Lecture Structure
| Time | Segment | Activity |
|---|---|---|
| 0:00–1:00 | **Midterm Exam** | Closed-book/notes per institutional policy, covers Weeks 1–8 |
| 1:00–1:10 | Break | — |
| 1:10–1:30 | Margin maximization | The maximum-margin hyperplane; support vectors |
| 1:30–1:50 | Soft margins | The `C` hyperparameter; tolerating some misclassification |
| 1:50–2:00 | The kernel trick (intro) | Mapping to higher dimensions implicitly; linear/polynomial/RBF |

### Materials/Equipment
- Printed/online exam; live-coding environment and scikit-learn for the SVM segment.

### Formative Check (in-class)
Exercise: on a small, linearly separable 2D dataset, identify by eye which points are likely
support vectors.

### Link to Lab/Assessment
Lab 9: SVM lab comparing linear, polynomial, and RBF kernels on linearly and non-linearly
separable data. **Capstone project introduced this week** — see
`assignments/capstone-proposal-guidelines.md`.
