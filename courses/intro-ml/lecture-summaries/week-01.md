# Week 1 Summary — Introduction to Machine Learning

**Key takeaways:**
- Machine learning algorithms improve at a task from experience (data) rather than fixed rules.
- The three major paradigms are supervised (regression/classification), unsupervised, and
  reinforcement learning; this course focuses on the first two, using classical/statistical
  methods rather than neural networks.
- The ML workflow is: split → preprocess → train → evaluate → iterate → final test evaluation.
- Overfitting/underfitting (the bias-variance tradeoff) can only be diagnosed by evaluating on
  data not used for training; the test set must stay untouched until the very end.

**You should now be able to:** distinguish supervised, unsupervised, and reinforcement learning
scenarios; correctly perform a train/test split; explain, at a conceptual level, why a test set is
necessary.
